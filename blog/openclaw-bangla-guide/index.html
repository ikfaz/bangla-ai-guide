ভূমিকা — মেহরাবের BillSmart-এ OpenClaw-এর প্রবেশ

২০২৬ সালের জানুয়ারির এক শীতের সকাল। মোহাম্মদপুরের একটা ছোট co-working space-এ মেহরাব হোসেন (২৯, BUET CSE ২০২০) তাঁর ল্যাপটপের সামনে বসা। তাঁর startup "BillSmart" — bKash/Nagad-এর জন্য automated invoicing SaaS — তখন মাত্র ৭ মাসের পুরনো। ৪ জনের team, ১২০-এর কাছাকাছি paying customer, প্রতিদিন ৩০-৪০টা support ticket। মেহরাব নিজে CTO + co-founder + (অপ্রকাশিতভাবে) tier 1 customer support। সমস্যা: প্রতিদিন রাত ১১টা পর্যন্ত WhatsApp আর Messenger reply করতে করতে actual coding-এর সময় নেই। Intercom-এর মতো paid SaaS chatbot — মাসে $১৫০ + per-message charge — startup-এর tight budget-এ afford করা যাচ্ছিল না। সেই দিন মেহরাব Hacker News-এ একটা post দেখলেন: "OpenClaw hits 100K GitHub stars in 48 hours." নিচে সাবটাইটেল: "the lobster way 🦞 — your personal AI agent, self-hosted, multi-channel"। দুই সপ্তাহ পর BillSmart-এর tier 1 support automation চালু হয়ে গেছে, খরচ মাসে $৩২, response time ২-৪ ঘণ্টা থেকে ৩০ সেকেন্ডে।

এই article মেহরাবের সেই journey-কে ঘিরে — OpenClaw আসলে কী, BD startup-এর জন্য কেন valuable, কীভাবে install করতে হয়, ২০২৬-এ এর reputation-এ যে controversy এসেছে, এবং honest verdict-এ আপনার ব্যবহার করা উচিত কি না।

OpenClaw কী + কেন viral হয়েছে

OpenClaw একটা open-source personal AI agent framework — Peter Steinberger (PSPDFKit-এর প্রতিষ্ঠাতা, প্রাক্তন iOS dev community-র চেনা মুখ) এর তৈরি। এটা Node.js-এ written, MIT-style license-এ released (commercial use-এর আগে license verify করবেন), এবং Mac/Linux/Windows + Docker-এ চলে। মূল idea: আপনার নিজের একটা "digital butler" যেটা WhatsApp, Telegram, Slack, Discord, iMessage সব জায়গা থেকে message receive করে, Claude/GPT/DeepSeek/Ollama-র মতো যেকোনো LLM ব্যাকএন্ড দিয়ে process করে, এবং 100+ pre-built skill ব্যবহার করে actual কাজ করে দেয় — ক্যালেন্ডারে event বসানো, invoice generate, GitHub PR review, এমনকি browser automate করা।

এর history short কিন্তু dramatic:

  • ২০২৫ মাঝামাঝি — Clawdbot: Peter একটা personal weekend project হিসেবে release করেন। নাম তখন "Clawdbot" — Claude-এর উপর একটা playful pun। প্রথম সংস্করণে শুধু Telegram + Claude API support ছিল।
  • ২০২৫ শেষ — Moltbot: Trademark concern এবং Anthropic-এর সাথে naming clash এড়াতে rename করে "Moltbot" রাখা হয় (lobster-এর moulting থেকে metaphor)। তখনই lobster mascot 🦞 আসে এবং "the lobster way" tagline establish হয়।
  • ২০২৬ জানুয়ারি — OpenClaw: আবার rename — "OpenClaw" — community-driven open-source positioning জোরালো করতে। সাথে সাথেই Hacker News, Twitter/X dev community, এবং Reddit r/selfhosted-এ explode করে।
  • ২০২৬ মার্চ: 247K GitHub star — initial 100K star আসে মাত্র ৪৮ ঘণ্টায়, যেটা GitHub-এর recorded history-তে fastest-growing repo।
  • ২০২৬ মে: 1.27M weekly npm download, 850+ contributor, May-র প্রথম ১৯ দিনে ১৫টা release।

মেহরাবের কথায়: "Hacker News-এ যেটা আমাকে hook করেছিল সেটা একটা GIF — একজন WhatsApp-এ লিখলো 'remind me to pay AWS bill tomorrow 10am', এবং পরের frame-এ Google Calendar-এ event বসে গেছে। আমার নিজের startup-এ সেটাই দরকার ছিল — ক্লায়েন্ট WhatsApp-এ যা চায়, system সেটা করে দিক।"

100+ built-in skills + skill marketplace

OpenClaw-এর "skill" মানে একটা specific কাজ করার pre-built capability — অনেকটা Anthropic-এর Claude Skills-এর মতো, কিন্তু agent context-এ। ২০২৬ মে-র registry-তে 120+ skill, যার মধ্যে BD startup context-এ relevant:

  • calendar-skill: Google Calendar/Outlook-এ event create, modify, list।
  • email-skill: Draft, send, search, summarize — IMAP/Gmail/Outlook।
  • github-skill: PR review, issue triage, comment, label।
  • notion-skill: Page create, database query, daily standup logging।
  • browser-skill: Headless browser দিয়ে website navigate, form fill, screenshot।
  • shell-skill: Local shell command run (sandboxed, with whitelist)।
  • invoice-skill (community): PDF invoice generate — BillSmart-এ মেহরাব এটাকে fork করে bKash/Nagad payment instruction যোগ করেছেন।
  • web-search-skill: Brave Search/SerpAPI/Tavily — current information lookup।
  • memory-skill: Long-term persistent memory — যা user বলেছিল ৩ সপ্তাহ আগে সেটাও মনে রাখে।
মেহরাবের observation: "Skill এর powerful দিক হলো TypeScript-এ যেকোনো একটা নতুন skill ১০০ লাইনে লেখা যায়। আমি BillSmart-এর জন্য একটা 'bkash-check-payment' skill বানিয়েছি — client যখন WhatsApp-এ লিখে 'taka pathaisi, check koren', agent automatically API call করে payment verify করে, invoice তে mark paid করে দেয়। যেটা আগে আমার ১৫ মিনিট লাগতো, এখন ৪ সেকেন্ড।"

বাংলাদেশ থেকে install — Mac/Linux/Windows + VPS

OpenClaw locally চালানো যায় (development-এর জন্য), কিন্তু 24/7 message receive করতে হলে একটা always-on server লাগে। মেহরাবের stack:

  • VPS: DigitalOcean Singapore region — $১২/মাস droplet (1 vCPU, 2GB RAM, 50GB SSD)। Latency BD-থেকে ~৬০ms — acceptable।
  • Alternative: Hetzner Finland — €৪.৫/মাস-এ একই specs পাওয়া যায়, কিন্তু latency BD-থেকে ~১৪০ms (mostly OK message lag-এর জন্য, real-time এ noticeable নয়)।
  • Payment: EBL Aqua/City Bank dual-currency card দিয়ে দুটোই কাজ করে — bKash সরাসরি unfortunately চলে না।
  • Install command: npm install -g openclaw তারপর openclaw init। Config wizard interactive — channel এবং LLM provider question করে।
  • Docker option: docker run -d openclaw/openclaw — preferred for production isolation।

Windows user-এর জন্য মেহরাবের warning: "WSL2-তে install দিন, native Windows install বেশ buggy। আমার teammate Tasnim প্রথমে Windows-এ try করে ৩ ঘণ্টা সময় নষ্ট করেছিল — পরে WSL2 Ubuntu-তে ১৫ মিনিটে done।"

Bring-your-own-key — যেকোনো LLM backend

OpenClaw কোনো hosted LLM dictate করে না — আপনার যেটায় convenience সেটাই connect করতে পারবেন:

  • Claude (Anthropic API): মেহরাবের পছন্দ — Sonnet 4.6, Bangla customer query handling-এ unmatched। মাসিক খরচ ~$২০।
  • GPT-5 (OpenAI): Image understanding বা voice transcription যদি core need হয়।
  • DeepSeek V3: Cheapest paid option — Bangla তে decent, খরচ মাসে ~$৩-৫ একই volume-এ।
  • Local Ollama (Llama 3.3 70B): Self-hosted, zero per-token cost — কিন্তু VPS তে 24GB GPU দরকার, যেটা $80+/মাস। Privacy-critical legal/healthcare data-র জন্য worth।
  • Hybrid: OpenClaw-এ "router" feature আছে — easy queries Llama-তে, complex Claude-তে — খরচ ৪০%-এর বেশি বাঁচানো যায়।

মেহরাবের ৬টা practical BD use case

২ সপ্তাহের active deployment-এর পর BillSmart-এ OpenClaw যেভাবে কাজ করছে:

  • ১. Customer support automation (tier 1): "kemne bill banabo", "subscription cancel korbo kemne", "Nagad add korbo na ken" — common 80% query agent solve করে। Escalation flag আসে শুধু complex বা angry tone detect করলে।
  • ২. FB Messenger auto-reply (community plugin): BillSmart-এর Facebook Page-এ ৩-৪ ঘণ্টার reply lag → ১ মিনিট। Tasnim এর confirmation: "client ৭০% বুঝতেই পারে না bot reply দিচ্ছে।"
  • ৩. Bangla query handling: "amar invoice ta kothay", "taka katise kintu paymentslip ashe nai" — Claude Sonnet 4.6-এর Bangla strength + OpenClaw-এর context retention = native-feel responses।
  • ৪. Invoice generation: WhatsApp-এ "Rahim Traders er jonno 12500 takar invoice banao" বললে — invoice PDF generate, WhatsApp-এ ফেরত, BillSmart database-এ logged।
  • ৫. Lead qualification: Cold lead যখন pricing জিজ্ঞেস করে — agent qualifying question করে (employee count, monthly transaction), tier recommend করে, sales call-এর জন্য Calendly link পাঠায়।
  • ৬. Internal team standup: Slack-এ প্রতিদিন সকাল ১০টায় agent জিজ্ঞেস করে "yesterday + today + blockers" — response সংগ্রহ করে Notion-এ standup log তৈরি করে।

২০২৬ controversy — security disasters + reputation hits

এখানে honest হওয়া দরকার, কারণ BD reader Hacker News-এর hype-এর বাইরে গিয়ে balanced view পাওয়ার অধিকার রাখেন। OpenClaw-এর ২০২৬-এ একাধিক serious incident হয়েছে:

  • February 2026 — RCE via skill manifest: Community skill marketplace-এর একটা malicious skill ("calendar-pro") install করলে remote code execution পেত। Patch দেওয়া হয়েছিল ৩৬ ঘণ্টার মধ্যে, কিন্তু ততক্ষণে ~৩,৪০০ self-hosted instance affected।
  • March 2026 — Email skill credential leak: Default config-এ IMAP password log-এ plaintext লেখা হতো। Researcher Tavis Ormandy এটা public করেছিলেন।
  • April 2026 — Medium viral post "OpenClaw is Dead": এক anonymous developer (BetterClaw fork-এর maintainer) যুক্তি দেন — Peter solo-maintain করছেন, governance দুর্বল, security review process নেই। Post-টা ১.৫ লাখ view পায়।
  • Branding instability: এক বছরে তিনবার rename — Clawdbot → Moltbot → OpenClaw — community-এ confusion এবং blog post/tutorial-এ stale instruction।
  • Ecosystem chaos: Skill marketplace-এ moderation দুর্বল — duplicate, abandoned, এবং occasionally malicious skill।
"আমি OpenClaw use করি কারণ alternative-এর tradeoff আমার জন্য worse। কিন্তু আমি Docker-এ চালাই, skill marketplace-এ যা install করি সব নিজে read করি, এবং কোনো sensitive data — যেমন BillSmart-এর actual payment credential — agent-এর reach-এ রাখি না। যারা 'install করে ভুলে যাও' মনোভাব নিয়ে আসে, তাদের জন্য এটা bad choice।" — মেহরাব হোসেন

Peter Steinberger নিজে এই issue গুলো acknowledge করেছেন এবং May 2026-এ একটা security audit team hire করেছেন, কিন্তু "production-ready for sensitive data" tag আসতে আরও সময় লাগবে।

Alternatives — যদি OpenClaw আপনার stack-এ না মানায়

  • Hermes Agent: Closed-source কিন্তু funded startup-এর তৈরি, better security posture, $২৯/মাস। বাংলাদেশী reader-এর জন্য আমাদের Hermes Agent বাংলা গাইড পড়ুন — comparable feature set, less DIY।
  • n8n: Visual workflow automation, self-hosted free। AI agent-এর জন্য purpose-built না কিন্তু "trigger-action" model BD freelancer-দের জন্য enough হতে পারে।
  • Activepieces: n8n-এর open-source competitor, AI step built-in, simpler UI।
  • Custom build (Claude Agent SDK): মেহরাবের পরবর্তী plan — OpenClaw থেকে eventually নিজস্ব minimal agent-এ migrate করা, Anthropic-এর official SDK ব্যবহার করে।

সীমাবদ্ধতা + careful use

  • Self-host overhead: VPS maintain, log monitor, security patch apply — সময় লাগে। Non-technical user-এর জন্য না।
  • Skill marketplace risk: যেকোনো skill install করার আগে source code পড়ুন।
  • LLM cost monitoring: Runaway loop-এ agent অনেক token খেয়ে fellte পারে — daily budget alert set করুন।
  • Bangla edge case: Mixed Bangla-English code-switching mostly fine, কিন্তু সম্পূর্ণ formal সাধু-ভাষা context-এ occasional misinterpretation।
  • Compliance: Customer data EU/USA server-এ গেলে BD-র upcoming Data Protection Act-এর সাথে clash হতে পারে — Singapore region preferred।
  • Vendor lock-in (subtle): ১২০+ skill OpenClaw-এর own format-এ লেখা — migration easy না।

উপসংহার — মেহরাবের পরামর্শ

BillSmart-এর tier 1 support এখন OpenClaw চালায়, প্রতি মাসে $১১৮ savings, এবং মেহরাব আবার রাতে coding-এ ফিরতে পেরেছেন। কিন্তু তাঁর পরামর্শ এই-ই: "যদি আপনি BD-র developer/founder হন, যিনি Linux server manage করতে পারেন, যিনি Docker চালাতে জানেন, এবং security tradeoff বুঝে নিতে রাজি — OpenClaw আপনার জন্য একটা serious value play। কিন্তু যদি আপনি সম্পূর্ণ non-technical হন, বা healthcare/finance-এর মতো highly regulated data নিয়ে কাজ করেন — Hermes Agent বা একটা professional SaaS choose করুন। 'Popular but proceed with caution' — এটাই OpenClaw-এর ২০২৬-এর সঠিক tag।" আজই যদি try করতে চান — DigitalOcean-এ $১২ droplet, Claude API key, এবং একটা টেস্ট WhatsApp Business number দিয়ে দুই ঘণ্টায় MVP চালু করা সম্ভব। কিন্তু production সব data আগে threat-model করে নেবেন।
