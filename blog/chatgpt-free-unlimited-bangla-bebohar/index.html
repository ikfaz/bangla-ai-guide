প্রকাশিত: ২৬ মে, ২০২৬

রাহিম আহমেদ ২০২৪-এর জুলাইয়ে ChatGPT Plus subscribe করেছিলেন। মাসে $২০, BD-তে ৳২,৪০০। তিনি ভেবেছিলেন paid plan ছাড়া কাজ চলবে না — সব tutorial বলে "Plus নাও।" তিনি সাব্‌স্ক্রাইব করেছিলেন ৬ মাস। মোট খরচ ৳১৪,৪০০। তারপর একদিন তিনি cancel করেছিলেন — পুরোপুরি free tier-এ আছেন গত ১১ মাস। তাঁর daily ChatGPT usage ৩৫-৫০ message। তাঁর কাজ ব্যক্তিগত content writing (Bangla blog), small business email, ছাত্রের জন্য study help। ১১ মাসে paid-এ ফিরে যাওয়ার দরকার পড়েনি। সাধারণ ChatGPT user-এর ৮৫% আসলে paid plan-এর দরকার নেই — কিন্তু ৬০% paid কিনে ফেলেন। এই article সেই reality এবং free tier-এর full playbook।

এক স্পষ্ট disclosure আগে: ChatGPT free tier "Unlimited" না — কিছু limit আছে। কিন্তু সেই limits ২০২৬-এ এত generous যে ৯০% BD user-এর জন্য সব দৈনিক কাজ chal-up। ছোট hack + smart usage = paid plan-এর ৮৫% capability $০-তে।

  • GPT-4o mini: True unlimited। প্রায় সব দৈনিক কাজ-এ যথেষ্ট।
  • GPT-5: Daily limited (gradual rate-limit, ~৩০-৫০ message per 3-hour window, account history depending)। বেশিরভাগ user hit করেন না।
  • Voice mode: Daily ১৫-২০ মিনিট free (Standard Voice, যা Bangla-তে natural)। Advanced Voice paid-এ।
  • DALL-E 4 image generation: দৈনিক ৩-৪টা image free।
  • File upload + analysis: Limited (1-2 PDF/day), small file size।

  • Custom GPTs: Browse + use — but cannot create।
  • Memory (cross-conversation): Available even on free tier।

রাহিমের ৭টা hack — যেগুলো free tier-কে paid-এর মতো বানায়

Hack 1: Long, structured prompts (1 message = 5 tasks)

Beginner: ৫টা message-এ ৫টা small task। GPT-5 limit hit হয় ৩০ মিনিটে।

রাহিমের approach: একটা message-এ ৫টা task batch করেন:

"আমাকে নিচের ৫টা কাজ একসাথে করো:
(১) এই Bangla email professional English-এ translate: [text]
(২) এই blog post-এর জন্য 3টা SEO title option: [paste]
(৩) এই product description-এ 'premium quality' phrase replace করে specific feature mention: [text]
(৪) আমার client-এর কাছে এই objection-এর প্রতি ২টা possible response: [paste]
(৫) এই week-এর আমার ৮টা task priority order: [list]"

একটা message, ৫টা task — limit consumption ৫× কম।

Hack 2: GPT-5-এর জন্য priority queue

রাহিমের সকালের রুটিন: GPT-5 (free quota)-এ যেগুলো দরকার complex reasoning-এ — সকালে সবার আগে সারেন। সারা দিনের simple task GPT-4o mini-তে। এই ordering-এ তাঁর Plus subscription-এর missed-feeling নেই।

Hack 3: Conversation-এর memory feature নিয়মিত প্রসারিত করুন

Free tier-এ ChatGPT Memory available। প্রথম conversation-এ আপনার full context inject করুন (পেশা, ভাষা, preference, frequent task)। পরবর্তী হাজার message-এ এই context auto-applied — context-setting-এর জন্য token খরচ ০।

Hack 4: Multi-AI fallback workflow

রাহিমের stack:

  • প্রথম: ChatGPT free tier (default)।
  • GPT-5 limit hit হলে: Claude free tier-এ switch (daily ১০-২০ message Sonnet 4.6, যা GPT-5-এর সমান)।
  • Claude limit hit হলে: Gemini Flash 3.5 (unlimited)।
  • Current data দরকার হলে: Perplexity Free (auto-search, citation)।
  • Coding-এ: DeepSeek free (unlimited, surprisingly strong)।

তিন-চারটা free tier একসাথে = effective $৬০-৮০/মাস capability।

Hack 5: Off-peak hours-এ run

Free tier rate limit relative — peak (US time evening) সময়ে aggressive limit, off-peak-এ relaxed। বাংলাদেশের সকাল ৭-১১টা US-এ গভীর রাত — সবচেয়ে generous time।

Hack 6: Custom Instructions setup

Free tier-এ Custom Instructions available। Settings → Personalization-এ:

  • "What would you like ChatGPT to know about you?": Background, role, language preference।
  • "How would you like ChatGPT to respond?": Format, length, tone।

প্রতি message-এ context সেট করতে হবে না — Custom Instructions auto-applied। Token saved।

Hack 7: Bangla prompt = token efficient

একটা subtle hack: Bangla-তে prompt গড়ে ৩০-৪০% কম token (compared to verbose English prompt-এর সঙ্গে)। যদি আপনি Bangla-তে comfortable হন, default Bangla rakhun — rate limit slower hit করবে।

সাবধান — "Unlimited ChatGPT" scam-এর কথা
