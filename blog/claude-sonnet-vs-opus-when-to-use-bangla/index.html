Combined workflow — দু'জনের সেরা

Tareq-এর startup-এ যে pattern চলে — অন্যরাও use করতে পারে:

  1. Daily kickoff: Sonnet 4.6 দিয়ে standup note generate, calendar plan, email triage।
  2. Coding (regular): Cursor + Sonnet 4.6 — ৮০-৯০% feature implementation।
  3. Hard problem detection: Sonnet ২ বার ভুল দিলে → manual escalation to Opus।
  4. Architecture decision (weekly): Opus 4.7-এ deep session, system design review।
  5. Document analysis: Short doc (<২০ page) → Sonnet; long doc (>৫০ page) → Opus।
  6. Customer email/standup recap (end of day): Sonnet — fast, cheap।

কখন Opus overkill (NOT Opus)

নিচের কাজে Opus use করবেন না — শুধু খরচ বাড়াবে, quality benefit নেই:

  • Simple email reply
  • Bangla content post (<১,৫০০ word)
  • Translation (Bangla ↔ English)
  • Single file code edit
  • Standard summarization
  • Casual brainstorm/idea
  • Customer support reply
  • Excel formula/basic data

কখন Sonnet-এ stuck — তখনই Opus

এই signal দেখলে Opus-এ switch:

  • Sonnet ২+ বার ভুল উত্তর দিয়েছে একই complex problem-এ
  • Multi-step problem-এ Sonnet step ৮-এর পর confused
  • ৫+ file jointly edit করতে hallucination
  • ৩০+ page document analysis-এ Sonnet partial answer
  • Bangla long-form (>৬,০০০ word) narrative inconsistent
  • Hard math/scientific reasoning (PhD-level)
  • Cross-reference accuracy critical (legal, financial)

উপসংহার — আপনার decision rule

সবচেয়ে honest rule এটাই: আগে Sonnet 4.6 দিয়ে চেষ্টা করুন। যদি ২ বার fail হয় OR task-এ ৫+ system/file জড়িত OR document ৩০+ পৃষ্ঠা — তখন Opus। অন্যথায় Sonnet-ই যথেষ্ট।
