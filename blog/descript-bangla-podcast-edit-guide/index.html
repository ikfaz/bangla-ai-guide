মূল ফিচার

1. Text-based editing

Audio → automatic transcript। Document-এ "ah", "um", "এ্য", "ইয়ে" সব visible। Select + delete → audio-ও delete। Tamzeed-এর মতে: "এটাই game-changer। Adobe Audition-এ waveform-এ scrub করতে যা ৩০ মিনিট, Descript-এ ৩ মিনিট।"

2. Studio Sound (AI noise removal)

Recording-এ AC noise, fan, room echo — এক click-এ professional studio-quality। Tamzeed Zoom recording (subject-এর variable audio) — Studio Sound apply করলে quality leveled।

3. Filler word removal (one-click)

"Remove filler words" — AI all "um"/"uh"/"so" detect + remove। Bangla-তে "মানে", "আচ্ছা", "ইয়ে" — manual mark করতে হয় (Bangla preset built-in না)। Time saved per episode ৩০-৪৫ মিনিট।

4. Overdub (voice cloning)

10-minute own voice training → AI voice clone। Mistake-এ extra word add করতে recording redo না — text type করলে cloned voice দেয়। English-এ excellent। Bangla-তে limited (২০২৬-এ improving)।

5. Multitrack editing

Interview-এ host + guest separate track। Independent edit।

6. Auto-chapter + show notes

Transcript থেকে AI auto-generate chapters + show notes। SEO description-এর জন্য valuable।

Podcast edit (basic workflow) — Tamzeed-এর routine

  1. Record (Zoom): Guest-এর সঙ্গে 60-90 min interview। Local recording on (Zoom feature)।
  2. Import to Descript: 2 audio files (host + guest) upload। Auto-transcription start (Bangla)।
  3. Review transcript (15 min): Bangla accuracy ~৮৫%। Manual fix major errors।
  4. Remove tangents (10 min): Off-topic ৫-১০ মিনিট cut। Document-এ paragraph delete।
  5. Filler word removal (5 min): "মানে"/"আচ্ছা" mark + bulk delete।
  6. Studio Sound apply (2 min): Both tracks balanced।
  7. Add intro/outro music (3 min): Pre-saved templates।
  8. Ad insertion (3 min): Sponsor read positioned।
  9. Export (10-15 min): MP3 + YouTube-ready video version।

Total: 50-60 মিনিট per episode (আগে ৪-৬ ঘণ্টা)।

বাংলা কাজে কতটা ভালো

  • Transcription: Bangla accuracy ~৮৫% (clean recording-এ ৯০%+)। Conversational speech-এ ৭৫-৮০%। Manual correction needed।
  • Filler word: Bangla preset নেই — manual mark।
  • Overdub: Bangla voice clone limited (২০২৬-এ research preview)। English-এ excellent।
  • Studio Sound: Language-agnostic — Bangla-তে same quality।
  • Auto-chapter: Bangla content-এ topic detection ~৭০% accurate।

প্রতিদ্বন্দ্বী

  • Adobe Audition: Industry standard, steeper learning curve, $20.99/মাস। Pro audio engineer-দের choice।
  • Hindenburg: Journalist/radio professional-দের জন্য। $12-24/মাস।
  • GarageBand: Mac free। Basic editing, no AI features।
  • Audacity: Free, open-source। Manual editing।
  • Riverside.fm: Podcast recording + light edit। $19/মাস।
