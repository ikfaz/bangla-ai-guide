Prompt-এর anatomy — ভালো prompt-এর ৫টা ingredient

একই কাজের জন্য ৫০ লাখ prompt আছে। কিন্তু সব ভালো prompt-এ এই ৫টা element থাকে:

  1. Role (কে responding): "তুমি একজন ৫ বছরের অভিজ্ঞতা সম্পন্ন Daraz top seller।"
  2. Context (পরিস্থিতি): "আমার shop জামদানি ও শাড়ি বিক্রি করে, monthly ৩৫টা piece। Target: 25-45 married women in Dhaka।"
  3. Task (নির্দিষ্ট কাজ): "আমার নতুন ৫টা product-এর জন্য Daraz listing description লেখো।"
  4. Format (output structure): "প্রতিটায়: 150-শব্দ Bangla description, ৫টা bullet feature point, ৩টা SEO keyword।"
  5. Constraint (limit/style): "Casual conversational tone। Generic phrase ('best quality', 'premium') avoid। Specific detail (fabric type, weaving region) inject।"

৫০ promp-এর প্রতিটায় এই ৫ ingredient-এর কম-বেশি আছে। আপনি যখন adapt করবেন — এই ৫ slot ভরে নিন।

প্রতিটি prompt কপি করে ChatGPT-এ পেস্ট করুন। যেখানে [...] আছে — সেখানে আপনার নিজের তথ্য বসান।

আশিকের actual adapted prompt — Daraz listing example

৫০ generic prompt-এর শক্তি adaptation-এ। আশিকের একটা real conversation দেখুন — Prompt #৬ ("product description") তিনি কীভাবে adapt করেছিলেন:

"তুমি একজন ৭ বছরের অভিজ্ঞতা সম্পন্ন Daraz top seller (৫% top performer)। আমার shop জামদানি ও কাঁথা সেলাই শাড়ি বিক্রি করে। নতুন একটা product আসছে — সোনারগাঁওয়ের কাঁথা-সেলাই-শাড়ি, hand-stitched, রঙ: গাঢ় লাল + সোনালি border। দাম ৳৪,২০০।

এই product-এর Daraz listing-এর জন্য:
১. Title (৬০ characters max, primary keyword 'কাঁথা শাড়ি সোনারগাঁও')
২. Short description (৫০ শব্দ Bangla, ক্রেতার pain point + solution)
৩. Long description (১৫০ শব্দ, ৫টা feature bullet, ৩টা care instruction)
৪. SEO tags (১০টা — Bangla + English mix)
৫. Pricing strategy advice: ৳৪,২০০ vs market range — competitive কিনা?

Style: Casual conversational, কাঁথা-সেলাই-এর heritage emphasize, generic phrase ('premium quality', 'best price') avoid।"

একই Prompt #৬ — কিন্তু ৫টা element-এ ভরা (role, context, task, format, constraint)। Output: ChatGPT যা generate করেছিল সেটা আশিক ৭০% as-is use করেছিলেন, ৩০% নিজের touch দিয়েছিলেন। সেই listing প্রথম সপ্তাহে ১৭টা piece বিক্রি — আগের listing-এর চেয়ে ৩.৪×।

৪টা common ভুল — যেগুলো ৮০% beginner করেন

  • 1. Context skip: "Marketing plan লেখো" → generic SaaS template। "আমি Daraz-এ জামদানি বিক্রি করি, monthly target $৮০০" → tailored, actionable plan।
  • 2. One-shot expectation: First answer rarely final। "আরো specific করো", "এই point-এ example যোগ", "৪০০-শব্দে compress" — iteration-এ real quality।
  • 3. No examples: "[paste 100-word sample of preferred style]" + "এই style-এ লেখো" — output instantly calibrate।
  • 4. Generic adjective: "creative", "engaging", "interesting" — meaningless। "৩টা rhetorical question দিয়ে শুরু করো", "প্রতি paragraph 60 শব্দের নিচে রাখো" — measurable instruction।

আশিকের ২৮টা saved prompt-এর প্রথমটা ছিল উপরের Prompt #৬-এর adapted version। তিন মাসে সেটা থেকে তিনি ২৮টা product-specific prompt build করেছেন। আপনিও আজই শুরু করুন: উপরের ৫০ prompt-এর মধ্যে এমন একটা বেছে নিন যা আপনার এই-সপ্তাহের একটা real task-এ apply হয়। ৫টা element (role/context/task/format/constraint) ভরে নিন। ChatGPT-এ চালান। আশিকের মতো ৩-৪ iteration-এ refine করুন। এই একটা saved prompt আপনার পরের ১০০টা version-এর foundation হবে — যেমন তাঁর জন্য হয়েছিল।

কনটেন্ট রাইটিং ও সোশ্যাল মিডিয়া — কী জানা দরকার?

১. "[বিষয়] নিয়ে ১,০০০ শব্দের একটি SEO ব্লগ আর্টিকেল লেখো, যেখানে H2, H3 ও bullet point থাকবে।" ২. "[প্রোডাক্ট] এর জন্য ৫টি Facebook ad copy লেখো — প্রতিটি ৬০ শব্দের মধ্যে, emotional hook দিয়ে শুরু।" ৩. "[বিষয়] নিয়ে একটি YouTube ভিডিওর জন্য ৩০-সেকেন্ডের আকর্ষণীয় hook লেখো।" ৪. "[টপিক] সম্পর্কে ১০টি short LinkedIn post idea দাও, প্রতিটি একটি বিতর্কিত মতামত নিয়ে।" ৫. "নিচের ব্লগ পোস্টের ৫টি সোশ্যাল মিডিয়া caption লেখো — Facebook, Instagram, LinkedIn-এর জন্য আলাদাভাবে।" ৬. "[ব্যবসা]-এর জন্য একটি product description লেখো — ৫০ শব্দে, ক্রেতার সমস্যা ও সমাধান উল্লেখ করে।" ৭. "একটি Instagram Reel-এর script লেখো [বিষয়] নিয়ে, ১৫ সেকেন্ডের, hook-script-CTA structure-এ।" ৮. "[ব্র্যান্ড নাম] এর…

প্রোডাক্টিভিটি ও পরিকল্পনা — কী জানা দরকার?

৩১. "আমার আজকের এই tasks-এর [পেস্ট] priority order বানাও — Eisenhower matrix অনুযায়ী।" ৩২. "[লক্ষ্য] অর্জনের জন্য ৯০ দিনের একটি action plan বানাও — সপ্তাহভিত্তিক milestone সহ।" ৩৩. "এই meeting notes-এর [পেস্ট] action items, decisions, owner আলাদাভাবে দাও।" ৩৪. "একটি SMART goal বানাও [আমার ইচ্ছা] নিয়ে।" ৩৫. "আমার সপ্তাহের জন্য একটি optimal time-block schedule বানাও — সকাল ৭ থেকে রাত ১১পর্যন্ত।" ৩৬. "[বই] পড়ার পর ৫টি actionable lesson বের করো।" ৩৭. "এই দীর্ঘ আর্টিকেলটি [পেস্ট] ৫টি bullet point-এ summarize করো।" ৩৮. "[সমস্যা] সমাধানের জন্য ৫-Why technique apply করো।" ৩৯. "আমার এই decision-এর [পেস্ট] pros ও cons table বানাও।" ৪০. "[প্রজেক্ট] এর জন্য সম্ভাব্য ১০টি risk এবং প্রতিটির mitigation…

আশিকের actual adapted prompt — কী জানা দরকার?

৫০ generic prompt-এর শক্তি adaptation-এ। আশিকের একটা real conversation দেখুন — Prompt #৬ ("product description") তিনি কীভাবে adapt করেছিলেন: "তুমি একজন ৭ বছরের অভিজ্ঞতা সম্পন্ন Daraz top seller (৫% top performer)। আমার shop জামদানি ও কাঁথা সেলাই শাড়ি বিক্রি করে। নতুন একটা product আসছে — সোনারগাঁওয়ের কাঁথা-সেলাই-শাড়ি, hand-stitched, রঙ: গাঢ় লাল + সোনালি border। দাম ৳৪,২০০। এই product-এর Daraz listing-এর জন্য: ১. Title (৬০ characters max, primary keyword 'কাঁথা শাড়ি সোনারগাঁও') ২. Short description (৫০ শব্দ Bangla, ক্রেতার pain point + solution) ৩. Long description (১৫০ শব্দ, ৫টা feature bullet, ৩টা care instruction) ৪. SEO tags (১০টা — Bangla + English mix) ৫. Pricing strategy advice:…

ব্যবসা ও মার্কেটিং — কী জানা দরকার?

২১. "[ব্যবসার ধরন] এর জন্য একটি সম্পূর্ণ marketing plan বানাও — মাসিক ৳৫০,০০০ বাজেটে।" ২২. "আমার [প্রোডাক্ট] এর জন্য target customer persona তৈরি করো — demographic, pain point, motivation সহ।" ২৩. "[প্রোডাক্ট] launch করার জন্য ৩০ দিনের সোশ্যাল মিডিয়া কনটেন্ট ক্যালেন্ডার বানাও।" ২৪. "একটি cold outreach email লেখো [target audience]-এর জন্য, ১০০ শব্দের মধ্যে।" ২৫. "[কম্পিটিটর] এর তুলনায় আমার ব্যবসার ৫টি unique selling point তৈরি করো।" ২৬. "একটি investor pitch-এর জন্য ৫-মিনিটের script লেখো [আমার startup idea] নিয়ে।" ২৭.
