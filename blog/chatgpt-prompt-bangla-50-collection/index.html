ChatGPT Prompt Bangla: ৫০টি সেরা কপি-পেস্ট প্রম্পট

ইকফাজ প্রতিষ্ঠাতা ও সম্পাদক

বাংলা AI গাইডের প্রতিষ্ঠাতা। বাংলাদেশি ব্যবহারকারীদের জন্য AI টুলস কিউরেট ও বিশ্লেষণ করেন — কোনটা BD থেকে কাজ করে, কোনটায় bKash চলে, কোনটা আসলে দৈনন্দিন কাজে লাগে।

প্রকাশিত: ২৬ মে, ২০২৬

ChatGPT-কে শুধু “Marketing plan লিখো” বা “Product description দাও” বললে উত্তর সাধারণ হওয়ার সম্ভাবনা বেশি। ভালো ফল পেতে prompt-এ কাজের প্রেক্ষাপট, নির্দিষ্ট লক্ষ্য, কাঙ্ক্ষিত format এবং সীমাবদ্ধতা পরিষ্কার করা দরকার। এই সংগ্রহের ৫০টি prompt সেই কাঠামো অনুসরণ করে সাজানো, যাতে নিজের তথ্য বসিয়ে দ্রুত ব্যবহার করতে পারেন।

এখানে কনটেন্ট, পড়াশোনা, ব্যবসা, পরিকল্পনা ও কোডিং—পাঁচটি বিভাগে prompt দেওয়া হয়েছে। এগুলো চূড়ান্ত উত্তর নয়; ChatGPT-এর output ব্যবহার করার আগে তথ্য যাচাই, নিজের ভাষায় সম্পাদনা এবং প্রয়োজনীয় privacy review করুন। শেষে একটি কাল্পনিক Daraz listing example দিয়ে prompt কীভাবে customize করবেন তা দেখানো হয়েছে।

Prompt-এর anatomy — ভালো prompt-এর ৫টা ingredient

একই কাজের জন্য ৫০ লাখ prompt আছে। কিন্তু সব ভালো prompt-এ এই ৫টা element থাকে:

  1. Role (কে responding): "তুমি একজন ৫ বছরের অভিজ্ঞতা সম্পন্ন Daraz top seller।"
  2. Context (পরিস্থিতি): "আমার shop জামদানি ও শাড়ি বিক্রি করে, monthly ৩৫টা piece। Target: 25-45 married women in Dhaka।"
  3. Task (নির্দিষ্ট কাজ): "আমার নতুন ৫টা product-এর জন্য Daraz listing description লেখো।"
  4. Format (output structure): "প্রতিটায়: 150-শব্দ Bangla description, ৫টা bullet feature point, ৩টা SEO keyword।"
  5. Constraint (limit/style): "Casual conversational tone। Generic phrase ('best quality', 'premium') avoid। Specific detail (fabric type, weaving region) inject।"

৫০ promp-এর প্রতিটায় এই ৫ ingredient-এর কম-বেশি আছে। আপনি যখন adapt করবেন — এই ৫ slot ভরে নিন।

প্রতিটি prompt কপি করে ChatGPT-এ পেস্ট করুন। যেখানে [...] আছে — সেখানে আপনার নিজের তথ্য বসান।

কনটেন্ট রাইটিং ও সোশ্যাল মিডিয়া (১-১০)

  • ১. "[বিষয়] নিয়ে ১,০০০ শব্দের একটি SEO ব্লগ আর্টিকেল লেখো, যেখানে H2, H3 ও bullet point থাকবে।"
  • ২. "[প্রোডাক্ট] এর জন্য ৫টি Facebook ad copy লেখো — প্রতিটি ৬০ শব্দের মধ্যে, emotional hook দিয়ে শুরু।"
  • ৩. "[বিষয়] নিয়ে একটি YouTube ভিডিওর জন্য ৩০-সেকেন্ডের আকর্ষণীয় hook লেখো।"
  • ৪. "[টপিক] সম্পর্কে ১০টি short LinkedIn post idea দাও, প্রতিটি একটি বিতর্কিত মতামত নিয়ে।"
  • ৫. "নিচের ব্লগ পোস্টের ৫টি সোশ্যাল মিডিয়া caption লেখো — Facebook, Instagram, LinkedIn-এর জন্য আলাদাভাবে।"
  • ৬. "[ব্যবসা]-এর জন্য একটি product description লেখো — ৫০ শব্দে, ক্রেতার সমস্যা ও সমাধান উল্লেখ করে।"
  • ৭. "একটি Instagram Reel-এর script লেখো [বিষয়] নিয়ে, ১৫ সেকেন্ডের, hook-script-CTA structure-এ।"
  • ৮. "[ব্র্যান্ড নাম] এর জন্য ১০টি tagline দাও, প্রতিটি ৬ শব্দের কম।"
  • ৯. "এই পুরোনো ব্লগ পোস্টটিকে [পেস্ট করুন] একটি modern, scannable version-এ rewrite করো।"
  • ১০. "[বিষয়] নিয়ে একটি Twitter thread লেখো — ১০টি tweet, প্রতিটি ২৮০ অক্ষরের মধ্যে।"

পড়াশোনা ও পরীক্ষার প্রস্তুতি (১১-২০)

  • ১১. "[বিষয়] সহজ বাংলায় ৫ বছরের বাচ্চাকে যেভাবে বোঝাবে সেভাবে ব্যাখ্যা করো।"
  • ১২. "[পাঠ্য বই-এর চ্যাপ্টার] থেকে ১০টি multiple choice প্রশ্ন তৈরি করো, সঠিক উত্তরসহ।"
  • ১৩. "নিচের নোটগুলো থেকে [পেস্ট করুন] ৫০ শব্দে একটি summary বানাও।"
  • ১৪. "[সাবজেক্ট]-এর জন্য একটি ১-সপ্তাহের পরীক্ষার প্রস্তুতি রুটিন বানাও — দিনে ৪ ঘণ্টা পড়ার জন্য।"
  • ১৫. "এই অনুচ্ছেদটি [পেস্ট] একটি mind map-এর জন্য visual hierarchy-তে সাজিয়ে দাও।"
  • ১৬. "BCS preliminary-এর জন্য [বিষয়] থেকে ৫০টি short question তৈরি করো।"
  • ১৭. "[কঠিন কনসেপ্ট] এর ৫টি বাস্তব জীবনের উদাহরণ দাও।"
  • ১৮. "এই গণিতের সমস্যাটি [পেস্ট] ধাপে ধাপে সমাধান করো, প্রতিটি ধাপের ব্যাখ্যা সহ।"
  • ১৯. "[বিষয়] নিয়ে একটি academic essay লেখো — ৫০০ শব্দে, intro/body/conclusion structure-এ।"
  • ২০. "নিচের লেখাটি [পেস্ট] Feynman technique ব্যবহার করে আমাকে শেখাও।"

ব্যবসা ও মার্কেটিং (২১-৩০)

  • ২১. "[ব্যবসার ধরন] এর জন্য একটি সম্পূর্ণ marketing plan বানাও — মাসিক ৳৫০,০০০ বাজেটে।"
  • ২২. "আমার [প্রোডাক্ট] এর জন্য target customer persona তৈরি করো — demographic, pain point, motivation সহ।"
  • ২৩. "[প্রোডাক্ট] launch করার জন্য ৩০ দিনের সোশ্যাল মিডিয়া কনটেন্ট ক্যালেন্ডার বানাও।"
  • ২৪. "একটি cold outreach email লেখো [target audience]-এর জন্য, ১০০ শব্দের মধ্যে।"
  • ২৫. "[কম্পিটিটর] এর তুলনায় আমার ব্যবসার ৫টি unique selling point তৈরি করো।"
  • ২৬. "একটি investor pitch-এর জন্য ৫-মিনিটের script লেখো [আমার startup idea] নিয়ে।"
  • ২৭. "[সমস্যা]-এর জন্য ১০টি innovative business idea দাও, প্রতিটিতে initial investment + market size সহ।"
  • ২৮. "আমার দোকানের [পণ্য] গুলোর জন্য ১০টি bundle offer suggestion দাও।"
  • ২৯. "একটি customer satisfaction survey বানাও [আমার ব্যবসা]-এর জন্য — ১০টি প্রশ্ন।"
  • ৩০. "এই negative review-এর [পেস্ট] একটি professional ও empathetic response লেখো।"

প্রোডাক্টিভিটি ও পরিকল্পনা (৩১-৪০)

  • ৩১. "আমার আজকের এই tasks-এর [পেস্ট] priority order বানাও — Eisenhower matrix অনুযায়ী।"
  • ৩২. "[লক্ষ্য] অর্জনের জন্য ৯০ দিনের একটি action plan বানাও — সপ্তাহভিত্তিক milestone সহ।"
  • ৩৩. "এই meeting notes-এর [পেস্ট] action items, decisions, owner আলাদাভাবে দাও।"
  • ৩৪. "একটি SMART goal বানাও [আমার ইচ্ছা] নিয়ে।"
  • ৩৫. "আমার সপ্তাহের জন্য একটি optimal time-block schedule বানাও — সকাল ৭ থেকে রাত ১১পর্যন্ত।"
  • ৩৬. "[বই] পড়ার পর ৫টি actionable lesson বের করো।"
  • ৩৭. "এই দীর্ঘ আর্টিকেলটি [পেস্ট] ৫টি bullet point-এ summarize করো।"
  • ৩৮. "[সমস্যা] সমাধানের জন্য ৫-Why technique apply করো।"
  • ৩৯. "আমার এই decision-এর [পেস্ট] pros ও cons table বানাও।"
  • ৪০. "[প্রজেক্ট] এর জন্য সম্ভাব্য ১০টি risk এবং প্রতিটির mitigation plan দাও।"

কোডিং ও টেকনিক্যাল (৪১-৫০)

  • ৪১. "Python-এ [কাজ] করার জন্য সবচেয়ে clean কোড লেখো, comment সহ।"
  • ৪২. "এই error message-এর [পেস্ট] সম্ভাব্য ৩টি কারণ ও সমাধান দাও।"
  • ৪৩. "এই কোডটি [পেস্ট] line-by-line ব্যাখ্যা করো বাংলায়।"
  • ৪৪. "এই SQL query-টিকে [পেস্ট] optimize করো এবং কেন তা ব্যাখ্যা করো।"
  • ৪৫. "[Web feature] তৈরি করার জন্য React কোড লেখো — TypeScript-এ।"
  • ৪৬. "এই কোডে [পেস্ট] security vulnerability খুঁজে বের করো।"
  • ৪৭. "[API endpoint] এর জন্য একটি cURL ও Postman example দাও।"
  • ৪৮. "এই কোডের [পেস্ট] unit test লেখো — Jest দিয়ে।"

  • ৫০. "[programming language] নতুনদের জন্য ৩০ দিনের শেখার roadmap বানাও।"

কাল্পনিক Daraz listing example — prompt customize করার পদ্ধতি

নিচের উদাহরণটি শেখানোর উদ্দেশ্যে তৈরি একটি কাল্পনিক scenario। Prompt #৬-এর সাধারণ product-description নির্দেশনাকে কীভাবে role, context, task, format ও constraint দিয়ে নির্দিষ্ট করা যায় দেখুন:

"তুমি একজন ৭ বছরের অভিজ্ঞতা সম্পন্ন Daraz top seller (৫% top performer)। আমার shop জামদানি ও কাঁথা সেলাই শাড়ি বিক্রি করে। নতুন একটা product আসছে — সোনারগাঁওয়ের কাঁথা-সেলাই-শাড়ি, hand-stitched, রঙ: গাঢ় লাল + সোনালি border। দাম ৳৪,২০০।

এই product-এর Daraz listing-এর জন্য:
১. Title (৬০ characters max, primary keyword 'কাঁথা শাড়ি সোনারগাঁও')
২. Short description (৫০ শব্দ Bangla, ক্রেতার pain point + solution)
৩. Long description (১৫০ শব্দ, ৫টা feature bullet, ৩টা care instruction)
৪. SEO tags (১০টা — Bangla + English mix)
৫. Pricing strategy advice: ৳৪,২০০ vs market range — competitive কিনা?

Style: Casual conversational, কাঁথা-সেলাই-এর heritage emphasize, generic phrase ('premium quality', 'best price') avoid।"

এখানে একই Prompt #৬-এ পাঁচটি element যোগ করা হয়েছে: role, context, task, format ও constraint। তৈরি হওয়া output সরাসরি প্রকাশ না করে পণ্যের সত্য তথ্য, মূল্য, care instruction এবং marketplace policy-এর সঙ্গে মিলিয়ে সম্পাদনা করুন।

৪টি সাধারণ prompt ভুল

  • 1. Context skip: "Marketing plan লেখো" → generic SaaS template। "আমি Daraz-এ জামদানি বিক্রি করি, monthly target $৮০০" → tailored, actionable plan।
  • 2. One-shot expectation: First answer rarely final। "আরো specific করো", "এই point-এ example যোগ", "৪০০-শব্দে compress" — iteration-এ real quality।
  • 3. No examples: "[paste 100-word sample of preferred style]" + "এই style-এ লেখো" — output instantly calibrate।
  • 4. Generic adjective: "creative", "engaging", "interesting" — meaningless। "৩টা rhetorical question দিয়ে শুরু করো", "প্রতি paragraph 60 শব্দের নিচে রাখো" — measurable instruction।

উপসংহার — আজকের ১০-মিনিট challenge

আজই উপরের ৫০টি prompt থেকে আপনার বাস্তব কাজের সঙ্গে মেলে এমন একটি বেছে নিন। Role, context, task, format ও constraint পূরণ করে ChatGPT-এ চালান, তারপর প্রয়োজন অনুযায়ী follow-up দিয়ে refine করুন। ভালো ফল পেলে promptটি সংরক্ষণ করুন এবং ভবিষ্যতে নতুন তথ্য দিয়ে হালনাগাদ করুন।
