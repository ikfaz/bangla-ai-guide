প্রকাশিত: ২৬ মে, ২০২৬

ভূমিকা — Rajshahi University-র student-এর first SaaS

রাজশাহী বিশ্ববিদ্যালয়ের CSE 2nd year student আফরিন সুলতানা — ২০ বছর, ২০২৪-এ admission। Programming basic (C, Python, basic web)-এ familiar, কিন্তু production-grade application deploy কখনো করেননি। ২০২৫ সেপ্টেম্বরে একটা hackathon-এর জন্য একটা mini-SaaS idea: "Bangladeshi student-দের জন্য course material organizer + study planner"। ১৪ দিন deadline। Local laptop dev environment-এ struggle (Postgres install, Node setup, dependencies)। Replit discover করলেন — browser-এ full IDE + database + deployment, AI Agent দিয়ে natural language-এ app build। ৪ দিনে functional MVP, hackathon-এ runner-up, prize ৳৪০,০০০। সেই app-ই এখন 600+ active student user। এই গাইড সেই workflow।

এই গাইডে যা থাকবে: Replit কী, প্রধান AI features (Agent, Assistant, Bounties), প্রথম app Agent দিয়ে ১০ মিনিটে, দাম, BD student/developer-এর জন্য use cases, টিপস, Replit vs Bolt vs Lovable।

Replit কী?

প্রধান AI ফিচার

  • Replit Agent: Natural language prompt → full functional app। "Build a study planner app with login, todo list, calendar view" → React + Node + DB স্কেলেটন delivered।
  • Replit Assistant (Ghostwriter): IDE-তে inline AI — autocomplete, refactor, explain, fix bug।
  • Multi-language support: Python, JS/TS, Go, Rust, Java, C++, Ruby — সব major।
  • Instant deploy: Click "Deploy" → app live URL। No DevOps knowledge needed।
  • Built-in DB: Replit DB (key-value) + PostgreSQL (Pro) — zero-setup।
  • Real-time collaboration: Google Docs-এর মতো — multi-user coding।
  • Bounties: Replit job marketplace — paid project freelancing (BD students-এর জন্য income opportunity)।

প্রথম app — Agent দিয়ে ১০ মিনিটে

Afrin-এর actual hackathon Day 1:
  1. replit.com → "Create with Agent" → prompt: "Build a Bangladeshi student study planner web app with: user signup (email), daily todo list, weekly study schedule, course material upload (PDF), exam countdown timer. Use React + Node.js + PostgreSQL."
  2. Agent processes (5-8 minutes)। Multiple files create।
  3. Initial functional app — basic styling, all CRUD operations।
  4. "Run" button → instant preview URL।
  5. Test signup → todo create → schedule add — works।
  6. Agent-এ next prompt: "Add Bangla language toggle and Hindu-Muslim holiday calendar"।
  7. Agent updates code — Bangla strings + holiday data add।
  8. 1 hour-এ MVP-এর core 70% complete।

Day 2-4: Custom features add manually + AI-assisted। UI polish। Day 5-6: Deploy + user testing।

দাম

  • Free: Public repls + basic AI (limited tokens)। 1 GB storage। Sleep after inactivity।
  • Replit Core $২৫/মাস: Private repls, more AI usage, always-on apps, more storage। Afrin-এর tier।
  • Teams $৩৫/user/মাস: Team collaboration, admin features।
  • BD payment: USD card via bKash recharge। Replit BD students-এর জন্য occasional regional discounts (verify in pricing page)।

বাংলাদেশি ছাত্র/developer-দের জন্য practical use

1. CSE student MVP / hackathon (Afrin-এর মতো)

Deadline-tight project, full-stack app, deploy needed — Replit Agent unmatched।

2. Learning programming (BD student)

Local laptop setup-এর struggle skip। Browser-এ full IDE + tutorial environments। Code.org-এর next step।

3. Freelance prototype delivery

Upwork client-এর জন্য quick prototype (MVP demo) — Replit-এ shareable URL। Iteration fast।

4. Side-project for income (Replit Bounties)

Replit Bounties marketplace-এ paid project pick — $৫০-৫০০ range typical। BD students-এর জন্য entry-level remote income।

5. Team class project (group of 4-6 students)

Real-time multi-user coding। University group project-এ Git conflict, environment difference — সব solved।

টিপস

  • Agent prompt detail: "Build study planner" vague → বেশি explicit better। "User signup with email, todo CRUD, calendar view with weekly grid, course material PDF upload (10 MB max), exam countdown widget"।
  • Iterate small: Agent-এর initial build-এ minor issues — small targeted prompt: "Add email verification step to signup"।
  • Manual edit don't fear: Agent-generated code review + edit। Generated code is starting point, not final।
  • Database choice: Replit DB simple project-এ, PostgreSQL complex-এ।
  • Deploy free tier: Sleep after 5 min inactivity। Always-on দরকার হলে Core tier।
  • Privacy: Free tier public। Private repls Core tier-এ।
  • Bangla content: UTF-8 fully supported। Database fields Bangla store smoothly।
