বাংলা AI গাইডের প্রতিষ্ঠাতা। বাংলাদেশি ব্যবহারকারীদের জন্য AI টুলস কিউরেট ও বিশ্লেষণ করেন — কোনটা BD থেকে কাজ করে, কোনটায় bKash চলে, কোনটা আসলে দৈনন্দিন কাজে লাগে।

প্রকাশিত: ২৬ মে, ২০২৬

Replit কী?

Replit হলো browser-based IDE — install কিছু লাগে না, browser-এ পুরো development environment। AI Agent feature যোগ হওয়ার পর সাধারণ ব্যবহারকারীও কোড না লিখে full-stack app বানাতে পারে।

প্রধান AI ফিচার

  • Replit Agent: বলুন কী চান, AI পুরো app বানিয়ে দেয়
  • Ghostwriter: Real-time code suggestion (Copilot-এর alternative)
  • AI Debug: Error explain ও fix suggest
  • Chat: Project-এর সম্পর্কে যেকোনো প্রশ্ন
  • Deploy: এক ক্লিকে live URL

প্রথম app — Agent দিয়ে ১০ মিনিটে

  • replit.com → Google login
  • "Create with AI Agent"
  • Prompt: "Build a habit tracker app where users can add daily habits, mark complete, and see a streak. Use React for frontend, simple database."
  • AI ৩-৫ মিনিটে scaffold করবে
  • Run → preview pane-এ live দেখুন
  • Iterate: "Add dark mode and login system"
  • Deploy → public URL

দাম

  • Free: Limited compute, public repls only
  • Core ($২০/মাস): Private repls, Agent access
  • Teams ($৪০): Multi-user collaboration
  • BD: International card / Stripe-friendly card

বাংলাদেশি ছাত্র/developer-দের জন্য practical use

  • University assignment: Web app submission
  • Portfolio project: Live demo URL সরাসরি CV-তে
  • MVP testing: Idea validate করার জন্য দ্রুত prototype
  • Learning: Tutorial follow without local install hassle
  • Freelance starter: Client-কে দ্রুত demo দেওয়া

টিপস

  • Free tier-এ project public — sensitive data না
  • Agent-এর first try perfect না — iterate করুন
  • Database-heavy app-এ Replit DB free tier-এ limit
  • Bolt.new/Lovable-এর সাথে compare করে দেখুন কোনটা আপনার style-এ ভালো

Replit vs Bolt vs Lovable

  • Replit: Full IDE feel, debug control বেশি
  • Bolt.new: দ্রুত prototype, less control
  • Lovable: Designer-friendly UI

উপসংহার

Browser-only environment, AI Agent — Replit beginner-friendly entry point। Free tier দিয়ে আজই একটি simple app বানান। Coding শেখার সবচেয়ে effective পদ্ধতি।
