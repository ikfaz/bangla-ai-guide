ভূমিকা

Midjourney prompt — শিল্প এবং বিজ্ঞান। ভালো prompt = magazine-quality ছবি। অস্পষ্ট prompt = generic output। এই গাইডে advanced techniques।

Prompt anatomy — 5 elements

  • Subject: "young Bangladeshi woman in saree"
  • Action: "walking through rice field"
  • Setting: "monsoon afternoon, lush green"
  • Style: "cinematic photography, 35mm film"
  • Parameters: "--ar 16:9 --v 6 --style raw"

Parameter cheat sheet

  • --ar 16:9 / 9:16 / 1:1: aspect ratio
  • --v 6: latest version
  • --style raw: less stylized, more realistic
  • --stylize 0-1000: default 100
  • --chaos 0-100: variety control
  • --quality 0.25-2: render quality
  • --no [thing]: exclude element
  • --seed [number]: reproducibility
  • --tile: seamless pattern

Weight syntax

  • Word::number: increase importance
  • "red dress::3, blue sky::1" — red dress 3x stronger
  • Negative weights: "dress::-1" (exclude/de-emphasize)
  • Multiple subjects balance

Style references (--sref)

  • Upload reference image
  • "--sref [image URL] --sw 100"
  • Style weight 0-1000
  • Multiple references: blend
  • Use case: brand consistency

Character references (--cref)

  • Character consistency across images
  • Upload portrait
  • "--cref [URL] --cw 100"
  • Same character, different scenes
  • Story-telling possible

Photography style keywords

  • Cameras: "shot on Canon 5D, Hasselblad H6"
  • Lenses: "50mm, 85mm prime"
  • Lighting: "golden hour, Rembrandt lighting"
  • Film stocks: "Kodak Portra 400, Fujifilm Velvia"
  • Genres: "cinematic, documentary, fashion editorial"

Art style keywords

  • Movements: "impressionism, art nouveau, cubism"
  • Artists (vague): "in the style of impressionist painter"
  • Mediums: "watercolor, oil painting, charcoal"
  • Decades: "1920s art deco, 1970s psychedelic"

10 advanced techniques

  • Niji mode: --niji 6 for anime
  • Permutations: "{a, b, c}" generate variants
  • Image prompting: URL + text combine
  • Pan/zoom: after generate, extend
  • Upscale subtle: add detail
  • Vary subtle: small variations
  • Remix mode: iterate on existing
  • Blend: 2-5 images merge
  • Describe: reverse-engineer prompt from image
  • Region select: modify specific area

Bangladesh-themed prompt examples

  • "Dhaka rickshaw at dusk, monsoon rain, neon lights reflecting on wet street, cinematic shot, 35mm film grain, Wes Anderson style --ar 16:9 --v 6"
  • "Bangladeshi grandmother making pitha in clay oven, warm yellow lighting, soft focus background, golden hour, documentary photography --ar 4:5"
  • "Cox's Bazar sunset, fishermen pulling nets, silhouettes against orange sky, drone shot, National Geographic style --ar 16:9 --style raw"

Common ভুল

  • Too many subjects (overwhelm)
  • Conflicting styles ("realistic anime cubist")
  • Vague description
  • No aspect ratio
  • Famous artists name (copyright)
  • Excessive parameters

Workflow — finished image in 10 min

  • Idea + reference search 2 min
  • First prompt + 4 variations 3 min
  • Pick best + variations 2 min
  • Upscale + minor edit 2 min
  • Export ready 1 min
