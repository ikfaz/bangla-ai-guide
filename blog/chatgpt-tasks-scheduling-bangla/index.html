১. ভূমিকা — Roni-র Tasks Adoption

রনি Cookups-এ join করার তিন মাস পর realize করলেন — তাঁর সকাল ৬টা থেকে ৭টা পুরোটাই information gathering-এ যাচ্ছে। Prothom Alo, Daily Star, Business Standard — তিনটা পড়া। তারপর Foodpanda, HungryNaki, Pathao Food-এর Facebook + Instagram check। তারপর Google Trends-এ "food delivery Dhaka" search। তারপর team standup-এর জন্য তিনটা talking point লেখা। সব মিলিয়ে ৪০ মিনিট। কিন্তু এই information তো standard — pattern recognition matter করে, raw data collection না।

২০২৫-এর জানুয়ারি-এ ChatGPT Tasks beta-এ available হলে রনি প্রথম যে task setup করলেন — "প্রতি সকাল ৬টায় Bangla news digest"। সাত দিন run করে দেখলেন output reliable। তারপর একে একে আরও ছয়টা task add করলেন। ২০২৬-এর মে-তে এসে তাঁর routine fundamentally বদলেছে।

Before/After: Morning routine ৪০ মিনিট manual → ৫ মিনিট review-only। Weekly competitive intel report manual research → automatic Saturday সকাল ৭টায় email। Daily news digest manual scanning → ৬টায় inbox-এ। Monthly content calendar planning ৩ ঘণ্টা → ৩০ মিনিট refinement।

২. ChatGPT Tasks কী + কীভাবে কাজ করে

ChatGPT Tasks হল OpenAI-এর scheduling feature যা ChatGPT-কে নির্দিষ্ট সময়ে নির্দিষ্ট prompt run করতে দেয় — user-এর interaction ছাড়া। 2025-এর January-এ launch হয়। মূল idea: repetitive query যেগুলো daily/weekly একই pattern-এ চলে, সেগুলো automate করো।

  • Recurring + one-time: "প্রতি দিন 6 AM" বা "শুধু আগামীকাল 3 PM"।
  • Web app + mobile: chatgpt.com থেকে setup, iOS/Android-এ result।
  • Email delivery: ChatGPT account email-এ notification + result।
  • Conversation thread: প্রতিটা task-এর আলাদা thread, history preserved।
  • Active limit: Plus tier-এ 10টা, Free tier-এ 1টা।

৩. Setup — Beta Access থেকে First Task

রনি যেভাবে শুরু করেছিলেন:

  • ChatGPT Plus subscription: $20/mo, bKash USD card বা Wise-এ payable। Free tier-এ Tasks limited (1 active)।
  • Model selector: chatgpt.com-এ top-এ "GPT-4o with scheduled tasks" select।
  • First prompt: "প্রতি দিন সকাল ৬টায় বাংলাদেশের top 5 business news summarize করে আমাকে পাঠাও।"
  • Confirmation: ChatGPT auto-detect করে scheduling intent, time + frequency confirm চায়।
  • Manage view: Profile → Tasks → সব active schedule, pause/edit/delete options।

প্রথম task setup-এ ২ মিনিট। Confirmation message-এ exact time + recurrence (daily/weekly/monthly/custom) verify করা important — না হলে wrong slot-এ schedule হবে।

৪. রনি-র ৭টা Actual Tasks

রনির current setup ২০২৬-এর মে অনুযায়ী — প্রতিটা task একটা specific marketing need address করে:

Task 1: Morning Bangla News Digest (6 AM daily)

Prompt: "Prothom Alo, Daily Star, Business Standard থেকে আজকের top 5 business + tech news বাংলায় summarize করো। প্রতিটা 2 sentence। Food + retail sector priority।" — রনি 6:30-এ ঘুম থেকে উঠে inbox-এ পান।

Task 2: Competitor Social Check (9 AM daily)

Prompt: "Foodpanda Bangladesh, HungryNaki, Pathao Food-এর Facebook + Instagram-এ last 24 hours-এ কী post করেছে summarize করো। Engagement pattern + campaign theme highlight।" — Office পৌঁছেই team-এ share।

Task 3: Weekly Market Trend (Saturday 7 AM)

Prompt: "এই সপ্তাহে Bangladesh food delivery industry-এ কী trend দেখা গেছে? Pricing, promotion, new launch, customer complaint pattern। Strategic implication for Cookups।" — Saturday সকালে coffee-র সাথে পড়েন।

Task 4: Monthly Content Calendar (1st-এর সকালে)

Prompt: "আগামী মাসের 30 days-এর জন্য Cookups social media content calendar suggest করো। Daily theme, Bangla caption draft, hashtag mix। বাঙালি food culture + seasonal angle priority।"

Task 5: Team Standup Talking Points (8:45 AM)

Prompt: "9 AM standup-এর জন্য আজকের 3টা priority talking point দাও — yesterday-এর key metric, today-এর focus, this-week blocker। Marketing team angle।" — Standup-এর 15 মিনিট আগে।

Task 6: Evening Reading Recommendations (8 PM)

Prompt: "Today-এর Marketing Brew, Stratechery, a16z blog থেকে 3টা relevant article recommend করো consumer brand marketer-এর জন্য। Each: title + 2-sentence why-it-matters।"

Task 7: Friday Brand Voice Check (Friday 4 PM)

Prompt: "এই সপ্তাহে Cookups-এর social media posts-এ brand voice consistency কেমন ছিল? Tone shift detect করেছ কোথাও? Improvement suggestion।" — Weekend planning-এর আগে।

Roni-র Reflection (মে ২০২৬): "৭টা task-এ আমি দিনে ৩৫ মিনিট save করছি। কিন্তু আসল লাভ time না — consistency। আগে busy দিনে competitor check skip করতাম। এখন automatic, 9 AM-এ inbox-এ। Information gap-এর strategic risk eliminated।"

৫. Bangla Content Scheduling Tips

Bangla output-এ Tasks-এর কিছু quirk আছে যা রনি trial-and-error করে শিখেছেন:

  • Explicit language instruction: "বাংলায় summarize" না বললে ChatGPT default English-এ যায়।
  • Tone specification: "Professional Bangla, সাধু না, conversational" — output quality 2x।
  • Source URL pin: Specific news site নাম দিলে ChatGPT browse করতে পারে; vague দিলে hallucinate করে।
  • Output format: "Bullet point, প্রতিটা 2 sentence" specify না করলে paragraph-এ আসে।
  • Bangla-English code-switching: Brand name (Cookups, Foodpanda) English রাখতে বলো — translate করলে weird হয়।
  • Time zone: Profile settings-এ Asia/Dhaka set করো — না হলে UTC-তে schedule হবে।

৬. Pro Features — Recurring, Conditional, Email

  • Recurring patterns: Daily, weekly (specific day), monthly (specific date), custom cron-style।
  • One-time scheduling: "আগামী সোমবার 3 PM" — interview prep, event reminder।
  • Conditional triggers (limited): "যদি AAPL stock 5%-এর বেশি move করে তাহলে alert" — beta, কখনো reliable কখনো না।
  • Email delivery toggle: Per-task setting — কিছু in-app, কিছু email, কিছু both।
  • Pause without delete: ছুটিতে গেলে task pause, ফিরে এসে resume — schedule reset হয় না।
  • Thread history: প্রতিটা task-এর past 30 runs visible, pattern analyze করা যায়।

৭. Privacy + Cost Considerations

রনি যেভাবে privacy + cost manage করেন:

  • Sensitive data exclusion: Company-confidential metric task prompt-এ দেন না — generic industry query।
  • Cookups internal data: Tasks-এ pull করেন না; manual review-এর সময় add করেন।
  • Cost predictability: Plus subscription $20 flat — Tasks usage extra charge নেই।
  • API alternative: Custom scheduling চাইলে OpenAI API + cron — কিন্তু Tasks-এর UI সহজ।
  • Account security: 2FA on, কারণ Tasks যে কেউ access করলে inbox-এ continuously data পাবে।
  • BD payment: bKash USD card monthly auto-renew; Wise alternative।

৮. সীমাবদ্ধতা

  • External API trigger নেই: Tasks শুধু ChatGPT-এর internal capability use করতে পারে — Zapier-এর মতো cross-app trigger না।
  • Real-time data limit: Browsing slow + sometimes outdated; breaking news-এর জন্য reliable না।
  • 10 active task cap: Plus tier-এ 11তম task add করতে হলে কোনো একটা pause/delete করতে হবে।
  • Timing precision: 6 AM scheduled task কখনো 6:03, কখনো 6:15-এ run হয় — exact second guarantee নেই।
  • Bangla quality variance: Daily output-এ inconsistent — কোনো দিন polished, কোনো দিন rough।
  • No multi-step workflow: Task A → Task B chain করা যায় না; প্রতিটা standalone।
  • Conditional trigger beta: "যদি X তাহলে Y" — reliability low, production-এ use না করাই ভালো।
