প্রকাশিত: ২৬ মে, ২০২৬

Prompt Engineering কী?

একই AI tool — একজনের output ভালো, অন্যজনের সাধারণ। পার্থক্য prompt-এ। Prompt Engineering হলো AI-কে সঠিকভাবে instruct করার বিজ্ঞান (এবং কিছুটা শিল্প)। এই গাইডে শিখবেন — কীভাবে এক prompt আপনার output ১০× ভালো করে।

মৌলিক ৬ Element-এর prompt

  • Role: "তুমি একজন senior copywriter..."
  • Task: "একটি Facebook ad copy লেখো..."
  • Context: "আমার product একটি bangla learning app..."
  • Format: "৬০ শব্দে, emotional hook দিয়ে শুরু..."
  • Examples: "যেমন: 'Don't learn English. Master it.'..."
  • Constraints: "এড়াও cliché, no emoji"

জনপ্রিয় Framework

RACE Framework

  • Role — AI-কে কী হতে বলছেন
  • Action — কী করতে
  • Context — পরিস্থিতি
  • Example/Expectation — output sample

CO-STAR Framework

  • Context
  • Objective
  • Style
  • Tone
  • Audience
  • Response format

Advanced Techniques

  • Chain-of-Thought: "ধাপে ধাপে চিন্তা করো, প্রতিটি ধাপ ব্যাখ্যা সহ"
  • Few-shot learning: ২-৩টা example দিয়ে pattern শেখান
  • Role-play: "তুমি একজন interviewer, আমি candidate..."
  • Self-critique: "এই answer-এর দুর্বলতা চিহ্নিত করো এবং উন্নত version দাও"
  • Persona: "একজন ৬৫ বছর বয়সী cardiologist হিসেবে উত্তর দাও"
  • Tree of thought: "৩টি সম্ভাব্য approach সমান বিচার করো"

Common ভুল

  • খুব ছোট prompt ("এই বিষয়ে কিছু লেখো")
  • Format specify না করা
  • উদাহরণ না দেওয়া
  • Context skip
  • Iterate না করা
  • এক prompt-এ অনেক কাজ

Bangla prompting tips

  • বাংলা context + English instruction mix সবচেয়ে effective
  • উদাহরণ: "Write in Bangla. ৪০০ word blog post on [topic]"
  • বাংলা output চাইলে output ভাষা specify
  • Technical term ইংরেজি রাখুন (translation awkward)
  • বাংলা style: "চলিত" vs "সাধু" specify

Iterative prompting

  • First output → "এটাকে আরো emotional করো"
  • "৩০% সংক্ষিপ্ত করো"
  • "আরও specific example যোগ করো"
  • "Tone professional-এ change করো"
  • "Critique এই output-এর সাথে"

Best prompt library তৈরি

  • Notion/Google Doc-এ আপনার সেরা prompt save
  • Use-case-ভিত্তিক organize
  • Result note (কোন AI-এ কেমন)
  • Team-এর সাথে share
  • নিজের custom GPT তৈরি repetitive কাজে

Model-specific tips

  • ChatGPT: Structured prompt লাভ
  • Claude: XML tag use করে কাজ specify কার্যকর
  • Gemini: Long context-এ best
  • Perplexity: Query-style direct

উপসংহার

AI-এর সাথে কাজ করা = AI-কে শেখানো কীভাবে কাজ করতে হবে। Prompt engineering শিখলে — আপনি AI dependent নন, AI আপনার শক্তিশালী সহকারী। আজকের একটি কাজে এই framework apply করে দেখুন।
