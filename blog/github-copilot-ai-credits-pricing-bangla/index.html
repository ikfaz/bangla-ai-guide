সংক্ষেপে

GitHub Copilot এখন পুরনো রিকোয়েস্ট গোনার বদলে GitHub AI Credits (Usage-based billing) নিয়মে চলে, যেখানে ১ AI Credit = $0.01 USD। পেইড প্ল্যানে কোড কমপ্লিশন ও Next Edit সাজেশন আনলিমিটেড ও ফ্রি থাকে; কেবল Copilot Chat, CLI ও Cloud Agent ব্যবহারে ক্রেডিট কাটে। Pro ($10/মাস) প্ল্যানে ১,৫০০ ক্রেডিট, Pro+ ($39/মাস) প্ল্যানে ৭,০০০ ক্রেডিট এবং Max ($100/মাস) প্ল্যানে ২০,০০০ ক্রেডিট পাওয়া যায়। ৩০ নভেম্বর ২০২৬ পর্যন্ত Copilot Fusion ব্যবহারে মডেল খরচে ৩০% ছাড় এবং অটো মডেল সিলেকশনে ১০% ছাড় চালু আছে।

নোট

তথ্য Plans for GitHub Copilot এবং Usage-based billing for individuals থেকে ৭ নভেম্বর ২০২৬ তারিখে নেওয়া। টাকা = ডলার × ১২৪.৩৫ (বাংলাদেশ ব্যাংকের ওজনযুক্ত গড় রেট, নিকটতম পূর্ণ সংখ্যা)। ভ্যাট ও কার্ডের চার্জ আলাদা।

GitHub AI Credits কীভাবে কাজ করে?

অনেক ডেভেলপার এখনো ভাবেন GitHub Copilot-এ আগের মতো মাসে নির্দিষ্ট সংখ্যক “Premium Requests” গোনা হয়। অফিসিয়াল ডকুমেন্টেশন অনুযায়ী, ২০২৬ সালের মাঝামাঝি থেকে সব ব্যক্তিগত ও টিম প্ল্যান GitHub AI Credits ব্যবস্থায় চলে গেছে। আপনি যখনই Copilot Chat, Copilot CLI বা Cloud Agent ব্যবহার করেন, তখন ইনপুট টোকেন, আউটপুট টোকেন ও ক্যাশড টোকেনের খরচের ওপর ভিত্তি করে ক্রেডিট হিসাব হয় (১ AI Credit = $0.01 USD)।

সবচেয়ে স্বস্তির বিষয় হলো: পেইড প্ল্যানে (Pro, Pro+, Max) সাধারণ Inline Code Completions এবং Next Edit Suggestions-এর জন্য কোনো AI Credit কাটে না—সেগুলো সম্পূর্ণ আনলিমিটেড। প্রতিটি পেইড প্ল্যানে দুটি অংশ থাকে: স্থির Base credits (যা শুরুতে খরচ হয়) এবং বাড়তি Flex allotment (বেস ক্রেডিট শেষ হলে স্বয়ংক্রিয়ভাবে চালু হয়)। প্রতি মাসের ১ তারিখ রাত 00:00:00 UTC (বাংলাদেশ সময় সকাল ৬টা)-তে ক্রেডিট রিসেট হয়। অন্য কোডিং টুলের তুলনা দেখতে GitHub Copilot প্রোফাইল ও Claude Code Pricing বাংলা গাইড দেখুন।

নিচের সারণিতে ব্যক্তিগত, শিক্ষার্থী ও টিম প্ল্যানের অফিসিয়াল ডলারের দাম, আনুমানিক টাকার হিসাব (১২৪.৩৫ টাকা/ডলার) এবং মাসিক মোট AI Credits দেওয়া হলো:

VS Code ও CLI-তে AI Credits বাঁচানোর উপায় কী?

অফিসিয়াল ডকুমেন্টেশন অনুযায়ী, আপনি কোন মডেল বেছে নিচ্ছেন এবং কত বড় কনটেক্সট পাঠাচ্ছেন তার ওপর ক্রেডিট খরচ নির্ভর করে। ভারী রিজনিং মডেল (যেমন Opus সিরিজ) এবং সমান্তরাল এজেন্ট ওয়ার্কফ্লো (/fleet) সবচেয়ে দ্রুত ক্রেডিট শেষ করে।

ক্রেডিট বাঁচিয়ে সারামাস নির্বিঘ্নে কাজ করার ৫টি কার্যকর ধাপ:

  1. অটো মডেল বা Copilot Fusion ব্যবহার করুন: পেইড প্ল্যানে চ্যাট ও ক্লাউড এজেন্টে Auto model selection রাখলে মডেল খরচে ১০% ছাড় মেলে, আর Copilot Fusion ব্যবহার করলে ৩০ নভেম্বর ২০২৬ পর্যন্ত ৩০% ছাড় পাওয়া যায়।
  2. সহজ কাজে হালকা মডেল বেছে নিন: ছোট বাগ ফিক্স, ইউনিট টেস্ট বা ডকস্ট্রিং লেখার সময় বড় ফ্রন্টিয়ার মডেলের বদলে Haiku বা হালকা মডেল নির্বাচন করুন।
  3. এজেন্ট মোডের আগে Plan Mode চালান: সরাসরি পুরো রিপোজিটরি এডিট করতে না বলে VS Code বা Copilot CLI-তে আগে Plan mode দিয়ে পরিবর্তনগুলোর পরিকল্পনা করে নিন।
  4. সেশন ক্রেডিট লিমিট সেট করুন: Copilot CLI বা ক্লাউড এজেন্টে বড় টাস্ক দেওয়ার আগে একটি সেশন ক্রেডিট ক্যাপ (AI credit limit) নির্ধারণ করুন যাতে অজান্তে পুরো মাসের বাজেট শেষ না হয়।
  5. এক্সটেনশন ও IDE আপডেট রাখুন: সঠিক ক্রেডিট হিসাব ও সতর্কবার্তা পেতে কমপক্ষে VS Code 1.120, JetBrains প্লাগইন 1.9.1 এবং Copilot CLI 1.0.48 ভার্সন ব্যবহার করুন।

বাংলাদেশের শিক্ষার্থী ও ডেভেলপাররা কীভাবে কিনবেন?

বাংলাদেশের বিশ্ববিদ্যালয় ও কলেজের শিক্ষার্থীরা বৈধ প্রাতিষ্ঠানিক ইমেইল বা স্টুডেন্ট আইডি কার্ড দিয়ে GitHub Student Developer Pack-এ আবেদন করলে Copilot Student প্ল্যান সম্পূর্ণ বিনামূল্যে পেতে পারেন। বিস্তারিত আবেদনের নিয়ম আমাদের GitHub Copilot বাংলা টিউটোরিয়াল ও শিক্ষার্থীদের জন্য AI গাইডে দেওয়া আছে।

পেইড প্ল্যান (Pro $10, Pro+ $39 বা বাড়তি AI Credits বাজেট) কেনার জন্য পাসপোর্ট এন্ডোর্সমেন্টসহ ডুয়াল-কারেন্সি ভিসা বা মাস্টারকার্ড প্রয়োজন। পেমেন্ট পদ্ধতি সম্পর্কে বিস্তারিত জানতে bKash দিয়ে AI tools কেনা যায় কি? গাইডটি পড়ুন।

সাধারণ কোড অটোকমপ্লিশন পেইড প্ল্যানে সম্পূর্ণ ফ্রি; তাই চ্যাট ও এজেন্ট মোডে শুধু প্রয়োজনীয় ফাইল যুক্ত করলেই $10-এর Pro প্ল্যানে পুরো মাস অনায়াসে কাজ চলে।

প্রকাশের আগে চেকলিস্ট

  • VS Code (কমপক্ষে 1.120) বা JetBrains প্লাগইন (1.9.1) আপডেট করেছেন।
  • Copilot Chat-এ ১০% ছাড়ের জন্য Auto model selection বা ৩০% ছাড়ের জন্য Copilot Fusion চালু করেছেন।
  • GitHub Billing পেজে অতিরিক্ত খরচের ঝুঁকি এড়াতে নিজের মাসিক বাজেট লিমিট ($0 বা নির্দিষ্ট অঙ্ক) সেট করেছেন।

সচরাচর জিজ্ঞাসা

GitHub AI Credits কী এবং ১ ক্রেডিটের দাম কত?

GitHub Copilot-এ চ্যাট, CLI ও এজেন্ট ব্যবহারের টোকেন খরচ এখন AI Credits দিয়ে মাপা হয়। অফিসিয়াল হিসাব অনুযায়ী ১ AI Credit সমান $0.01 USD (অর্থাৎ $10 বাজেটে ১,০০০ AI Credits পাওয়া যায়)।

কোড অটোকমপ্লিশন ব্যবহারে কি AI Credits কাটে?

না। Copilot Pro, Pro+ ও Max-এর মতো সব পেইড প্ল্যানে সাধারণ কোড কমপ্লিশন এবং Next Edit Suggestions সম্পূর্ণ আনলিমিটেড এবং এতে কোনো AI Credit খরচ হয় না।

Copilot Pro ($10) প্ল্যানে মাসে কত ক্রেডিট পাওয়া যায়?

Copilot Pro ($10/মাস, প্রায় ৳১,২৪৪) প্ল্যানে মাসে ১,০০০ Base credits এবং ৫০০ Flex allotment—মোট ১,৫০০ AI Credits দেওয়া হয়।
