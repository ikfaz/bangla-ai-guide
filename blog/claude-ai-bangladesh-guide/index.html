বাংলা AI গাইডের প্রতিষ্ঠাতা। বাংলাদেশি ব্যবহারকারীদের জন্য AI টুলস কিউরেট ও বিশ্লেষণ করেন — কোনটা BD থেকে কাজ করে, কোনটায় bKash চলে, কোনটা আসলে দৈনন্দিন কাজে লাগে।

প্রকাশিত: ২৪ মার্চ, ২০২৬

শারমিন আক্তার Dhaka-র একজন senior copywriter — একটা leading agency-তে ৮ বছরের অভিজ্ঞতা। ২০২৪-এ তিনি ChatGPT Plus-এ ছিলেন। ২০২৫-এর জুন-এ তিনি একটা long-form Bangla brand story লিখতে গিয়ে বুঝেছিলেন ChatGPT-এর Bangla prose "কোথাও যন্ত্রের মতো শোনায়।" তিনি একই prompt Claude Sonnet 4.6-এ চালালেন — "আমার breath stopped" বললেন। Sentence-rhythm, Bangla idiom, emotional pacing — সবকিছু publication-grade। সেই দিন থেকে তিনি Claude Pro-তে। আজ ১১ মাস পর তিনি বলেন তাঁর monthly client revenue ৪২% বেড়েছে — কারণ তাঁর Bangla brand stories detection-proof হয়েছে এবং clients তাঁর rate $০.১৮ থেকে $০.৩৫/word-এ accept করেছেন। AI tool নয়, "tool fit" বদলেছিল।

এই article Claude-এ specifically কী জন্য — কোন কাজে Claude সবচেয়ে এগিয়ে, কোথায় ChatGPT/Gemini-এর সাথে compare করলে underperform, BD-থেকে access ও pricing, এবং Projects/Computer Use-এর মতো features যেগুলো বেশিরভাগ user জানেন না।

Claude-এর model family — যা ২০২৬-এ matter করে

Anthropic-এর AI lineup ২০২৬-এর মাঝামাঝিতে:

  • Claude Sonnet 4.6: Flagship daily-driver। Best Bangla prose, exceptional coding (SWE-bench leader), 200K context window। Free tier daily limited, Pro unlimited।
  • Claude Opus 4.7: Most powerful। Extended Thinking mode, complex multi-step reasoning, agentic workflow। Max tier ($১০০-২০০) unlimited, Pro tier limited usage।
  • Claude Haiku 4.5: Fast/cheap। API integration-এ ideal। Free tier-এ default for high-volume task।
  • Computer Use (beta): Claude একটা virtual screen-এ click করে, type করে, files navigate করে — actual autonomous task execution। Workflow automation-এর next generation।
  • Projects: Context-preserved workspace। প্রতি project-এ ১০০+ documents upload + custom instructions। Repeating workflows-এর জন্য game-changer।

BD থেকে Claude-এ signup ও payment

  1. Website: claude.ai — VPN ছাড়া accessible from Bangladesh।
  2. Sign up: Google account / email + phone OTP (+880 accepts)।
  3. Mobile app: Android + iOS — full feature parity with web।
  4. Free tier: Sonnet 4.6 limited daily (~১০-২০ message), file upload limited, Projects 1 free।
  5. Pro ($২০/মাস): Sonnet 4.6 unlimited, Opus 4.7 limited daily quota, unlimited Projects, file upload bigger।
  6. Max ($১০০ or $২০০/মাস): Opus 4.7 unlimited, higher rate limits, priority access। Power user tier।
  7. BD payment: bKash USD virtual card (Bank Asia, City Bank, EBL), Payoneer, Wise — সব accept।

Claude-এর ৫টা feature যা সবার জানা দরকার

1. Projects — Context-preserved workspace

শারমিনের সবচেয়ে valuable feature। প্রতি client-এর জন্য একটা separate Project — সেখানে brand guideline, past article, tone-of-voice document, persona, FAQ-সব upload করা। নতুন article লেখার সময় Claude সব context-এ access করে।

উদাহরণ: তাঁর "Pathao Brand Project"-এ ৩৭টা source — ২০২২-২০২৬-এর সব Pathao campaign, brand book, founder interview, customer review pattern। নতুন brand story লেখার আগে context-setting শূন্য — Claude সব জানে।

2. Extended Thinking (Opus 4.7)

Complex multi-step problem-এ Claude "চিন্তা করে" — ১-৫ মিনিট। Result quality dramatic difference। Math, strategy, code-debug, decision analysis।

3. Artifacts — Inline interactive output

Code, document, HTML, SVG diagram — Claude inline-এ generate করে এবং preview দেয়। React component তৈরি করুন, immediately render দেখুন। Coding workflow-এ time-saver।

4. Computer Use (beta)

Claude-কে দিন একটা task ("download my Gmail inbox-এর last 10 invoices, organize in Drive folder by month")। Claude actual screen-এ navigate, click, type, file save করে। ২০২৬-এর agentic workflow-এর first real implementation।

5. Vision (image understanding)

Image upload করে question ask করুন। Bangla handwritten document, screenshot, chart, photo — Claude analyze, explain, transcribe। বাংলা handwriting OCR-এ Claude reasonably accurate।

শারমিনের actual daily workflow — Bangla copywriter

  • সকাল ৯টা: Project open (current client)। "এই brand-এর tone-of-voice অনুযায়ী একটা ১,২০০ শব্দের Mother's Day campaign story-এর outline দাও।"
  • সকাল ১০টা: Outline approved। "প্রতি section-এ ২০০ শব্দের draft, কিন্তু আমার personal voice preserve করো — আমি client-এর past article-এ যেমন লিখেছি।" Claude past article reference করে style match।
  • দুপুর ১টা: Self-edit (২৫-৩০% rewrite)।
  • বিকাল ৪টা: Final pass — "এই draft-এ ৩টা hedge phrase ('আমি মনে করি', 'হতে পারে') identify করো এবং stronger alternative দাও।"

৩-৪ ঘণ্টায় client-grade article। Pre-Claude সেই কাজ ২ দিন নিত।

Claude-এর সীমাবদ্ধতা — যা ChatGPT/Gemini-তে আছে

  • No image generation: Vision-এ image বুঝে, কিন্তু generate করে না। DALL-E/Imagen/Midjourney-এর সমতুল্য নেই।
  • No voice mode (still beta): ChatGPT Voice-এর সমতুল্য feature limited।
  • No native web search: Browse capabilities limited compared to Gemini/Perplexity।
  • No Workspace integration: Gmail/Sheets-এ inline operate করে না (Computer Use beta-তে partial)।
  • Smaller context than Gemini: 200K vs 1M-2M tokens। 500-page PDF-এ chunking দরকার।

Claude কাদের জন্য — সিদ্ধান্ত-গাছ

  • Content writer/blogger/journalist (especially Bangla): Claude Pro primary।
  • Full-stack developer: Claude Pro + Claude Code (API integration)।
  • Researcher (long-form analysis): Claude Pro।
  • Academic (essay, thesis): Claude Pro for writing, Perplexity for citation।
  • Multimodal creator (video, image, voice): ChatGPT Plus more practical।
  • Google Workspace heavy: Gemini Advanced more efficient।
  • Budget = ০: Claude Free + Gemini Free + ChatGPT Free combo।

উপসংহার — আপনার আজকের পদক্ষেপ

শারমিন বলেন: "Tool comparison-এ ৭০ benchmark numbers-এর চেয়ে important — আপনার এক actual কাজ। আপনার last week-এর হার্ড task ৩ AI-তে paste করুন। যেটার output আপনি as-is publish করতে পারেন — সেটাই আপনার AI।" আজই করুন: claude.ai-এ free account খুলুন (Gmail দিয়ে), আপনার সবচেয়ে কঠিন এই-সপ্তাহের writing/coding/analysis task Claude-এ চালান। যদি output 2× better হয় — Pro $২০-এর জন্য 14-day trial নিন। আপনার next 30 days-এর work-এ Claude-ই আপনার fit কিনা সেটা automatic decide হয়ে যাবে।
