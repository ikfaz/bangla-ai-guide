ভূমিকা

Bdjobs — বাংলাদেশের #১ job portal, ১০০,০০০+ active job, ১ কোটি+ registered user। যেকোনো position-এ শতাধিক applicant। আপনার application কীভাবে stand out করবে — AI workflow।

Profile optimization (Bdjobs)

  • Profile photo: professional headshot (AI generated possible)
  • Headline: keyword-rich title
  • Career objective: AI-crafted, role-specific
  • Skills: industry-specific, top 10-15
  • Education: complete + verified
  • Work experience: action-verb, result-quantified
  • Profile complete 100% — Bdjobs algorithm boost

CV — AI optimization

  • Format: Single column, ATS-friendly
  • Length: 1-2 pages (entry) / 2-3 (mid-senior)
  • Sections: Contact, Summary, Experience, Education, Skills, Projects, References
  • Action verbs: "Led, Managed, Increased, Implemented"
  • Numbers: "Increased sales 25%", "Managed team of 15"
  • Keywords: Match job description exactly

ATS optimization

  • Plain font (Calibri, Arial)
  • No fancy graphics/columns
  • Job title exact match
  • Acronym + full form (SEO + Search Engine Optimization)
  • PDF + Word both versions ready
  • AI prompt: "Make this CV ATS-friendly for [job title]"

Cover letter — AI workflow

  • Job description analyze → key requirements
  • AI prompt: "Cover letter for [role] at [company]. My CV: [paste]. Tone: confident professional. Length: 250-350 word."
  • Customize each application (no copy-paste)
  • Bangla cover letter for govt/local
  • English for MNC/international

Application strategy

  • Quality > Quantity (10 well-tailored > 50 generic)
  • Match score self-check before apply
  • Set Bdjobs job alerts
  • Apply within 24-48 hours of posting
  • Follow up if no response (1 week)

Networking via Bdjobs

  • Connect with employees of target company
  • LinkedIn + Bdjobs combined
  • Referral: 5-10x application success
  • Industry-specific Facebook group
  • BD HR community engagement

Interview prep (post-application)

  • Company research (AI deep dive)
  • Common questions practice (ChatGPT roleplay)
  • Behavioral STAR method
  • Salary negotiation script
  • Bilingual: Bangla + English ready

Salary negotiation

  • Bdjobs salary range research
  • AI roleplay: 5 rounds practice
  • Counter-offer scripts
  • Benefits beyond salary
  • Avoid first number (let them disclose)
  • BDT vs USD (multinational)

Job categories — BD specific

  • Banking/finance: high competition, specific skills
  • RMG merchandising: English + technical
  • NGO: mission-driven cover letter
  • Government: BCS preparation
  • Tech: portfolio essential
  • MNC: English fluency critical

Common ভুল

  • Generic CV mass-apply
  • Cover letter same for every job
  • No customization per JD
  • Spelling/grammar mistake
  • Outdated information
  • No follow-up
