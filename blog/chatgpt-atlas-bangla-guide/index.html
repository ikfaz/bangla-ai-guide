বাংলা AI গাইডের প্রতিষ্ঠাতা। বাংলাদেশি ব্যবহারকারীদের জন্য AI টুলস কিউরেট ও বিশ্লেষণ করেন — কোনটা BD থেকে কাজ করে, কোনটায় bKash চলে, কোনটা আসলে দৈনন্দিন কাজে লাগে।

প্রকাশিত: ২৭ মে, ২০২৬

Banani-র কো-ওয়ার্কিং স্পেসে সকাল ৯টা। Rifat Khan, ২৭, NSU CSE ২০২১ ব্যাচ — একটা BD fintech startup-এর competitive intelligence researcher। কাজ এক লাইনে: প্রতিদিন ৮-১২টা BD ও regional competitor সাইট monitor করা, পরিবর্তন ধরা, product team-এর জন্য summary দাঁড় করানো। ২০২৫-এর শেষ পর্যন্ত তার দৈনিক রুটিন ছিল — Chrome-এ ৩০+ tab খোলা, একেকটা সাইটে গিয়ে pricing page, blog, careers page, app store review — সব নিজে পড়া, copy-paste করা, Google Doc-এ note করা। দৈনিক ৪-৫ ঘণ্টা শুধু এই research-এ যেত। ২০২৬-এর জানুয়ারিতে যখন ChatGPT Atlas — OpenAI-এর নিজের browser — তার Mac-এ install হলো, তিন সপ্তাহ পরে সেই ৪-৫ ঘণ্টা নেমে এলো ১ ঘণ্টায়। Weekly research output দ্বিগুণ। Rifat বলেন — "Atlas Chrome নয়, Chrome-এর জায়গায় বসা একটা researcher।"

এই article-এ Rifat-এর workflow ধরে ChatGPT Atlas-এর সম্পূর্ণ গাইড — কী, কেন গুরুত্বপূর্ণ, BD থেকে কীভাবে access, ৬টা মূল feature, Agent mode-এর শক্তি, পাঁচটা practical BD use case, এবং সীমাবদ্ধতা।

ভূমিকা — Banani-র Rifat-এর Research Transformation

Rifat-এর কাজের প্রকৃতি বুঝলে Atlas-এর value স্পষ্ট হবে। তার fintech startup BD-র ৬টা wallet competitor track করে — bKash, Nagad, Rocket, Upay, Tap, Sure Cash। সঙ্গে regional comparison — India-র PhonePe, Paytm, Pakistan-এর Easypaisa। এর বাইরে ২টা global fintech (Wise, Revolut) ও inspiration হিসেবে monitor হয়। প্রতিদিন তাকে এই ১০-১১টা সাইট ছুঁতে হতো — pricing change হলো কিনা, নতুন feature launch হলো কিনা, blog-এ কী ঘোষণা এলো, app store-এ user-রা কী complaint করছে।

Rifat-এর পুরনো workflow (Dec ২০২৫): সকাল ৯টায় Chrome খুলে ১১টা bookmark-এ click। ৩৩টা tab খুলে গেল (প্রতি site-এ pricing + blog + reviews)। প্রতিটা পড়া → Google Doc-এ paste করা → হাইলাইট করা → শেষে summary লেখা। দুপুর ২টা পর্যন্ত শুধু এটাই। বাকি দিন Slack-এ team-কে findings পাঠানো, Notion update করা, weekly report লেখা। সপ্তাহে real "analysis" করার সময় ছিল ৪-৫ ঘণ্টা — বাকি ৩৫ ঘণ্টা data gathering।

২০২৬-এর জানুয়ারিতে OpenAI ChatGPT Atlas-এর Windows beta রিলিজ করল (Mac version ছিল ২০২৫-এর October থেকে)। Rifat-এর MacBook Air M2-তে install করলেন, ChatGPT Plus subscription bKash USD card-এ চলছিলই — পরে Pro-তে upgrade করলেন। তিন সপ্তাহ পরে workflow পুরো পাল্টে গেল। এখন সকাল ৯টায় Atlas-এ একটা session-এ সব ১১টা site browse, ChatGPT sidebar-এ instant summary, Agent mode-কে বলে দেওয়া "এই ৬টা competitor-এর pricing page check করো এবং changes flag করো" — দুপুর ১০:৩০-এর মধ্যে কাজ শেষ। ১ ঘণ্টা।

ChatGPT Atlas কী এবং কেন গুরুত্বপূর্ণ

ChatGPT Atlas হলো OpenAI-এর প্রথম নিজস্ব web browser, যা ২০২৫-এর October-এ Mac-এর জন্য launch হয়। এটি Chromium-এর উপর তৈরি — মানে Chrome-এর সব site, extension compatibility, password sync এখানেও কাজ করে। কিন্তু পার্থক্য একটাই, এবং সেটাই সব — ChatGPT এই browser-এর কেন্দ্রে integrated, sidebar বা pop-up নয়, পুরো browsing experience-এর অংশ।

কেন এটা গুরুত্বপূর্ণ? কারণ গত ২০ বছরে browser মানে ছিল URL bar + tabs + bookmark। Information খুঁজে বের করা, পড়া, copy করা — সব user-এর কাজ। Atlas সেই paradigm ভাঙছে: browser নিজে read করতে পারে, summarize করতে পারে, ক্লিক করতে পারে, form fill করতে পারে। Chrome-এ AI extension (যেমন Monica, Sider) দিয়ে কিছুটা কাছাকাছি যাওয়া যেত, কিন্তু সেগুলো bolted-on। Atlas-এ AI native।

  • Launch date: ২০২৫ October (Mac), ২০২৬ Q1 (Windows beta)।
  • Base: Chromium — Chrome extensions, bookmarks import সব support।
  • Integration: ChatGPT split-screen / sidebar, সবসময় available।
  • Tier requirement: Plus ($20/mo) minimum, Agent mode Pro ($200/mo) only।
  • BD থেকে: VPN লাগে না, USD card via bKash-এ payment চলে।

বাংলাদেশ থেকে Access ও Install

Atlas BD থেকে access করা সহজ — কিন্তু কিছু গুরুত্বপূর্ণ পয়েন্ট আছে যেগুলো Rifat নিজে hands-on শিখেছেন।

  • Download: chatgpt.com/atlas — সরাসরি, VPN লাগে না।

  • Windows (beta): Q1 ২০২৬-এ release। Windows 11 প্রায় bug-free, Windows 10-এ কিছু rendering issue।

Rifat-এর tip: "প্রথমে Plus tier-এ ১৫ দিন try করুন। Agent mode ছাড়াই daily research time ৫০% কমে যাবে। Pro-তে upgrade করুন যখন বুঝবেন Agent mode-এর জন্য আপনার repetitive multi-step workflow আছে — যেমন আমার ৬টা competitor pricing check।"

মূল ৬টি Feature

Atlas-এর সব feature-ই যে নতুন তা নয় — Chrome + ChatGPT extension কিছুটা এমন করতে পারে। কিন্তু এই ৬টা feature একসাথে, native-ভাবে এবং Pro tier-এ Agent mode সহ — সেটাই Atlas-এর সম্মিলিত power।

  • ১. Split-screen ChatGPT: যে কোনো page-এর পাশে ChatGPT permanent থাকে। URL এ যেতে হয় না, Cmd+L এ ChatGPT call।
  • ২. Browser memory: Cross-session context সংরক্ষণ। গত সপ্তাহে যে ১৫টা site পড়েছেন সেগুলোর সারাংশ Atlas মনে রাখে — "last week-এ Nagad-এর কী পড়েছিলাম?" jaal চলে।
  • ৩. Agent mode: Autonomous browsing — AI নিজে click, type, navigate করে। (Pro-only, বিস্তারিত নিচে)।
  • ৪. Summarize page: এক ক্লিকে current page-এর সারাংশ — Bangla output সমর্থিত।
  • ৫. Ask about page: Page-এর content নিয়ে question — "এই blog-এ pricing-এর কথা কোথায়?"
  • ৬. Automated tasks: Recurring workflow save — "প্রতিদিন সকাল ৯টায় এই ১০টা সাইট check করো"।
Rifat-এর Browser Memory experience: "January-র দ্বিতীয় সপ্তাহে আমি bKash-এর blog-এ একটা remittance bonus পড়েছিলাম। তিন সপ্তাহ পরে team meeting-এ কেউ জিজ্ঞেস করল 'BD wallet-গুলো remittance-এ কী incentive দিচ্ছে?' — আমি Atlas-এ লিখলাম 'গত মাসে remittance নিয়ে যা পড়েছি দেখাও' — instant ৪টা page-এর summary। Notion-এ search করতে আমার ২০ মিনিট লাগত।"

Agent Mode — Atlas-এর সবচেয়ে শক্তিশালী Feature

Agent mode-ই কারণ যেজন্য Rifat Pro tier-এ গেছেন। সাধারণ AI chatbot আপনাকে বলে "এই কাজটা এভাবে করুন।" Agent mode কাজটা নিজে করে দেয় — browser-এর মধ্যে click, type, scroll, navigate সব। এটা একটা virtual employee-র মতো — যাকে instruction দিলে browser-এ গিয়ে task complete করে আসে।

"আমি Atlas-এর Agent mode কে বললাম — 'bKash, Nagad, Rocket-এর pricing page check করো, send money fee গত মাসের সাথে compare করো এবং changes report করো।' সাত মিনিট পরে একটা table পেলাম: Rocket-এর fee P2P-তে 5 টাকা কমেছে, Nagad-এ unchanged, bKash-এ একটা নতুন tier যোগ হয়েছে। আগে এই কাজে আমার ৪৫ মিনিট লাগত — pricing page-এ pricing-এর actual numbers খুঁজে বের করা, Excel-এ note করা, পার্থক্য বের করা।" — Rifat Khan

Agent mode কীভাবে কাজ করে: আপনি একটা task লিখে দেন → AI নিজে browser tab খোলে → URL-এ যায় → page পড়ে → relevant section খুঁজে বের করে → data extract করে → পরের site-এ যায় → শেষে structured output দেয়। আপনি real-time-এ AI-এর প্রতিটা click দেখতে পারেন, intervene করতে পারেন।

সীমাবদ্ধতা: Agent mode সব site-এ একই rate-এ কাজ করে না। JavaScript-heavy single-page app-এ কখনো struggle করে। CAPTCHA এলে human-কে call করে। Login required site-এ আপনি আগে log in করে রাখলে চলে, নাহলে credentials দিতে refuse করে (security)।

Rifat-এর ৫টি Practical BD Use Case

তিন সপ্তাহ Atlas ব্যবহারের পরে Rifat একটা list বানিয়েছেন — কোন কোন কাজে তার সবচেয়ে বেশি সময় বেঁচেছে। সবগুলোই BD context-এ।

Use Case ১ — Competitor Monitoring: ৬টা BD wallet competitor-এর pricing, blog, careers page প্রতিদিন automated check। Agent mode সকাল ৯টায় নিজে run হয়, ৭ মিনিটে summary Slack-এ pinned মেসেজ হয়ে আসে। আগে: ২ ঘণ্টা manual। এখন: ০ minute Rifat-এর তরফ থেকে।
Use Case ২ — BD News Daily Digest: Prothom Alo, Daily Star, bdnews24, Dhaka Tribune — প্রতিদিন business/tech section থেকে fintech-related news Atlas extract করে। বাংলা article-এ summarize Bangla-তে দেয়, English article-এ English-এ। ১০ মিনিট/দিন।
Use Case ৩ — Daraz Price Tracking: ৪টা competitor product Daraz-এ track — দাম পরিবর্তন হলে notification। Atlas নিজে Daraz pageload করে, price element identify করে, history log রাখে। ২০২৫-এ Rifat এই কাজে একটা separate Python script চালাতেন — এখন Atlas-এ একটা saved task।
Use Case ৪ — Govt Notice Monitoring: Bangladesh Bank-এর regulatory notice, BTRC announcement, MFS guideline — fintech-এর জন্য critical। Atlas এই সরকারি সাইটগুলো (যেগুলো প্রায়ই PDF-heavy, formatting messy) নিজে scan করে, নতুন notice flag করে, Bangla summary দেয়। আগে এই কাজ team-এ একজন full-time intern-এর ছিল।
Use Case ৫ — Market Research Synthesis: Quarterly report-এর সময় Rifat-কে ৪০-৫০টা source থেকে data টানতে হয় — Statista, World Bank, BIDS report, news article। Atlas-এর memory feature-এ সব session-এর reading saved। Report লেখার সময় "গত quarter-এ MFS adoption-এ যা পড়েছি তার সব key statistics দাও" — instant।

সীমাবদ্ধতা ও Privacy Considerations

Atlas perfect নয়। Rifat যেটাকে honest assessment বলেন: কিছু জিনিস Chrome এখনো ভালো করে।

  • Privacy concern: Atlas আপনার browsing history-র context থেকেই কাজ করে। সব data OpenAI server-এ যায় (memory feature on থাকলে)। Sensitive work — banking, medical — এ আলাদা Chrome profile use করা ভালো।
  • Bangla quality medium: Sonnet 4.6 বা Gemini 3.5-এর সাথে compare করলে Atlas-এর Bangla output literary নয়, কিন্তু extractive task (summarize, list) এ ভালো।
  • Pro tier expensive: $200/mo BD context-এ অনেক — ২৪,০০০ টাকা। ROI তখনই যখন daily ৩+ ঘণ্টা research।
  • Agent mode unreliable on SPAs: React/Vue heavy site (যেমন Bkash app web) মাঝে মাঝে fail।
  • Battery drain: Mac-এ Chrome থেকে ১৫-২০% বেশি battery খায়, GPT inference cost।
  • Limited extension ecosystem: Chrome extension চলে কিন্তু Atlas-specific extension এখনো নেই।
Privacy tip: Atlas-এ Settings → Memory → Disable for sensitive sites। Banking, personal email — এসব site-এ memory off রাখলে data OpenAI-এ যায় না।

উপসংহার — কাদের জন্য Atlas Worth It

Atlas সবার জন্য নয় — এটা Chrome-এর replacement হিসেবে market-এ আসেনি। এটা একটা specialized tool, specific power user-দের জন্য। Rifat-এর মতো competitive intelligence researcher, market analyst, journalist যারা প্রতিদিন ১০+ source থেকে information process করেন — তাদের জন্য Pro tier-এর $200 ৩-৪ ঘণ্টার hourly rate-এ পুষিয়ে যায়। একজন occasional user-এর জন্য Chrome + ChatGPT.com tab-ই যথেষ্ট।

Worth it যদি — daily research-heavy job, ১০+ site monitor করতে হয়, repetitive multi-step task আছে, ChatGPT Plus ইতিমধ্যে subscribe করেছেন। Skip যদি — casual browsing, occasional AI query, privacy-sensitive industry-তে কাজ করেন, বা $200 mo বাজেটে নেই।

Rifat-এর শেষ কথা: "Atlas browser নয়, একটা workflow shift। Chrome-এ আমি information খুঁজতাম, Atlas-এ information আমাকে আসে। ২০২৬-এ যে researcher এটা early adopt করবে, তার output competitor-দের চেয়ে ২x — এই gap বছর শেষ হওয়ার আগে close হবে না।" আজই chatgpt.com/atlas-এ গিয়ে download, ChatGPT Plus account-এ login, একটা daily task automate করে দেখুন — সাত দিনের মধ্যে decision স্পষ্ট হবে।
