Install (VS Code)

  1. VS Code Extensions tab → "Codeium" search → install
  2. Sidebar-এ Codeium icon click → "Sign up free"
  3. Google/GitHub OAuth (fastest, no email verification delay)
  4. Privacy toggle: Settings → Codeium → "Block training on my code" → ✓
  5. Default model: Codeium proprietary (fast)। Premium chat-এ Claude Sonnet 4.6 use।

JetBrains IDE (IntelliJ/PyCharm)

  1. Settings → Plugins → "Codeium" search → install
  2. Restart → sign in

Vim/Neovim

  1. vim-plug বা packer.nvim-এ Codeium plugin add
  2. :Codeium Auth → browser-এ OAuth complete

প্রধান ফিচারসমূহ

  • Tab autocomplete: Type করতে শুরু করলে greyed text-এ multi-line suggestion। Tab key দিয়ে accept।
  • Inline chat: Ctrl+Shift+L (selected code) → "Refactor this", "Add error handling", "Explain"। Quick edit।
  • Sidebar chat: @-mentions support — @codebase, @file, @function। Whole repo aware।
  • Slash commands: /explain, /test, /docstring, /fix। Frequent task shortcut।
  • Multi-language: Python, JS, TS, Go, Rust, Java, C++, Ruby, PHP, Bash — সব main। Niche language (Solidity, Dart) decent।
  • Bangla instruction works: "এই function-এ error handling add করো" perfectly understood।

Practical use cases — Tanvir-এর actual experience

Use case 1: Internship work (PHP Laravel)

Agency-র legacy Laravel codebase-এ feature add — Tanvir Codeium Tab-এ ৭০% boilerplate auto-complete। Manual logic implementation শুধু। Daily 4-5 hour-এর কাজ 2 hours-এ। ৩ মাসে confidence build।

Use case 2: Personal portfolio project (React + Node)

Side-project — একটা food delivery prototype। Codeium chat-এ @codebase ব্যবহার করে: "এই project-এ auth flow কেমন? Improve সাজেশন।" Detailed answer + code suggestion।

Use case 3: LeetCode/competitive programming

Daily ৩-৫টা problem। Codeium-কে: "এই problem-এ আমার hint কী?" Step-by-step nudge (full solution না)। Independent thinking train।

Use case 4: Documentation

প্রতি project-এ README + JSDoc। /docstring command-এ entire function documentation auto-generate। মূল্যবান time saver।

Use case 5: Open-source contribution

Hacktoberfest-এ ৭টা PR merged। Codeium @codebase-এ "এই project-এর coding convention কী?" — first contribution-এর hassle কম।
