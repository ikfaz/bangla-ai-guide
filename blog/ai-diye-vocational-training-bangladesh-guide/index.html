এই গাইডে যা থাকবে: BD-র TVET landscape, instructor-side AI workflow, student support, soft skills, certification, job placement, female-specific TVET, modern skills addition (CAD, IoT, basic coding), এবং migrant workers-এর জন্য language + skill prep।

১. Instructor workflow AI

Hafiz-এর Sewing Machine instructor case

৩৫ জন trainee। Instructor Aminul (১৫ বছর গার্মেন্টস experience কিন্তু lesson plan নেই)। Hafiz তাঁকে ChatGPT teach করলেন:

  • Lesson plan: "Sewing Machine Operation 12-week curriculum-এর week 5 lesson plan — flat lock machine introduction। ৩ ঘণ্টা session, ২ ঘণ্টা theory + ১ ঘণ্টা practical। Bangla-তে।"
  • Assessment: "Week 5-এর জন্য practical test rubric — ৫টা skill point, prog/standard/excellent benchmark।"
  • Visual aid: "Flat lock machine-এর parts diagram — Bangla labeling সহ।" (ChatGPT description, পরে hand-draw)
  • Troubleshooting guide: "Flat lock-এ ১০টা common problem + solution — Bangla-তে।"

Aminul-এর daily prep time: ৩ ঘণ্টা → ৪০ মিনিট। Student feedback improved।

২. Practical skill AI assist

  • Step-by-step demos: YouTube link curate করতে ChatGPT-কে: "Flat lock machine threading-এর সেরা ৩টা Bangla/Hindi YouTube tutorial।"

৩. Student support — beyond classroom

৪. Soft skill development

BD TVET-এ সবচেয়ে অবহেলিত — কিন্তু job retention-এ critical।

  • Communication: ChatGPT-এ daily role-play — "Factory supervisor-কে কীভাবে leave request করবেন? Polite Bangla এবং English-এ।"
  • Time management: Schedule template, Pomodoro intro।
  • Problem solving: Case study — "Machine break হলে আপনি কী করবেন?" → group discussion + AI synthesis।
  • Financial literacy: Salary management, bKash savings, MFS use।

৫. Certification + assessment

  • BTEB certification — Hafiz students-দের জন্য mock exam prep (AI-generated)।
  • NSDA NTVQF (National Technical and Vocational Qualifications Framework) Level 1-4 mapping।
  • Practical assessment rubric — AI-generated per trade।
  • Portfolio (sewing samples / wiring diagram / repair report) — AI-assisted documentation।

৬. Job placement support

Hafiz-এর placement workflow:
  • ৪০টা partner factory (RMG, AC service, electric workshop)
  • প্রতি batch graduation-এর ১ মাস আগে AI-এ CV template-এ প্রত্যেকের info plug — Bangla + English version

৭. Female-specific TVET

BD-তে female TVET enrollment ২২% (national average)। Hafiz-এর target ছিল ৪০%। Achieved ৩৭%।

  • Trade focus: Sewing, Beauty, Tailoring, Computer Operation, Mobile Repair (যেগুলোয় female-friendly perception)

৮. Modern skills addition (২০২৬-এর demand)

  • CAD basic (AutoCAD/SketchUp): Construction worker-দের জন্য — drawing read + simple modification।
  • IoT basics: Electrician-দের জন্য — smart device install/repair।
  • Basic coding (Python/HTML): Computer operator-দের জন্য — extra skill।
  • Digital tools: WhatsApp Business, Google Maps, Excel basics।
  • AI literacy: ChatGPT-এ work-related query কীভাবে করবেন।

এই additions-এর জন্য AI সবচেয়ে valuable — instructor কম, curriculum self-paced, video resource AI-curated।
