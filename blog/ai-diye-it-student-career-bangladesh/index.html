২০২৬-এ BD CSE Graduate Reality

  • ৬৫,০০০+ annual CSE graduate BD-তে (BUET, DU, NSU, EWU, IUT, AIUB, BRACU, RU, KU, CU)।
  • Entry-level dev job listing: মাসিক ৪,০০০-এর কাছাকাছি।
  • Ratio: ~১৬:১ (graduate per job)।
  • Top 10% earners ৳৬০K+ starting: Pathao, bKash, ShopUp, Chaldal, Brain Station 23।
  • Middle 60% ৳২০-৪০K starting: SME software house।
  • Bottom 30% jobless after 1 year: Mostly portfolio-less, no internship experience।

আদিলের 4-Year Roadmap — replicable

Semester 1-2: Foundation + first project

  • Core CS: Python (CS50 Python free), Git/GitHub basics।
  • First project: "BD weather CLI tool" — API call, JSON parse। GitHub upload।
  • AI tutor: ChatGPT-এ concept explanation। NotebookLM-এ lecture upload।
  • Goal: GitHub profile alive। ১-২ project।

Semester 3-4: Specialization choice

  • Bottom-up specialization: Web Dev (React + Node) vs Mobile (React Native) vs Data (Python + ML) vs DevOps।
  • AI mentor: "আমার interest-গুলো এই, BD job market-এ ২০২৭-এ কোন specialization-এ best ROI?" Claude-এর strategic input।
  • Project intensify: 5-7 portfolio project।
  • LinkedIn build: Profile, 2-3 weekly post।

Semester 5-6: Internship preparation

  • Cursor AI + Claude Code: Pair-programming partner। 10x productivity।
  • Open-source contribution: Bangla-language tool, BD-localization PRs।
  • Internship application: Spring + Summer। Pathao, bKash, Brain Station, Chaldal — top 5 internship target।
  • Goal: Paid internship secured (৳১৫-৩৫K stipend)।

Semester 7-8: Job-ready + thesis

  • Capstone thesis with AI: Claude Opus-এ research synthesis।
  • Job-search active: 5-10 application/week।
  • System design prep: "Designing Data-Intensive Applications" + AI mock interview।
  • Goal: Pre-graduation full-time offer।

AI Tool Stack — Student Edition (৮০% Free)

  • Cursor AI: Code IDE। Free tier basic, Pro $২০/mo (worth it Year 3 onwards)।
  • Claude Code: CLI agent। API $$ — Free tier alternative: ChatGPT Plus inline code।
  • NotebookLM: 100% free। Lecture upload, podcast-style revision।
  • GitHub Copilot: Free for students with .edu/verified student status।
  • Claude/ChatGPT free: Daily concept explanation, debug, code review।
  • Perplexity free: Research, citation।
  • JetBrains: Free student license — IntelliJ, PyCharm, WebStorm।

Total student investment: ০-$২০/মাস। Premium tools mostly free with student email।

  • JetBrains IDE (worth $250)।
  • Heroku, DigitalOcean free credit ($৩০-১০০)।
  • Microsoft Azure $১০০ credit।
  • Datadog, Sentry, MongoDB Atlas free tier।
  • Free domain (.me, .live)।
  • Canva Pro (1 year free)।

Total value: $৩,০০০+। 80% BD CSE students-এর কাছে available, but unused।

Income while Studying

  • Upwork micro-tasks: $৫-২০/hour starting। React/Node fast-grow।
  • Local SME web dev: ৳১৫,০০০-৫০,০০০ per static site।
  • Online tutoring (10MS / Onnesha): ৳৩০০-৮০০/hour।
  • Open-source bug bounty: $৫০-৫০০ per accepted bug।
  • Realistic Year 3-4 income: ৳১৫-৪০K/মাস part-time।

Post-Graduation Paths

  • BD top tech (Pathao, bKash, etc.): ৳৪০-৮০K starting + RSU/bonus।
  • BD SME software house: ৳২৫-৪০K starting।
  • Remote international: $২০-৫০K USD/year (Upwork retainer / Toptal / Andela-style)।
  • Higher studies: US/EU MS, GRE/IELTS prep।
  • Startup founder: Pre-seed angel investor connect during university।

৪টা failure pattern — ৮৫% CSE graduate stuck

  • 1. No GitHub portfolio: Resume-only application — never shortlisted। Minimum 10 quality project।
  • 2. Late internship pursuit: Year 4-এ apply শুরু — too late। Year 2-3-এই start।
  • 3. CGPA obsession alone: CGPA ৩.৫+ যথেষ্ট। তার পরে projects + skills matter।
  • 4. Generalist forever: "I do everything" — no specialization edge। ১টা vertical-এ deep specialize।

উপসংহার — আপনার আজকের পদক্ষেপ

আদিল বলেন: "আমার classmate-রা এখনো GitHub-এ নেই। তাঁরা ভাবেন CGPA + IELTS = job। ২০২৬-এ সত্য: portfolio + open-source contribution + AI-augmented productivity = job। আমি ৮ মাসে যা পেয়েছি — সবার পক্ষে possible, যদি Year 2 থেকে শুরু করেন।" আজই করুন: GitHub Student Pack apply করুন (education.github.com/pack)। Cursor AI ইনস্টল করুন। আপনার current সেমিস্টারের একটা assignment-কে portfolio project-এ convert করুন — README, screenshot, deployment। ১ মাসে আপনি ১টা public project পাবেন। সেটাই শুরু — আদিলের ১৪ project-এর প্রথম।
