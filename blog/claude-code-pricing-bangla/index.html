সংক্ষেপে

Claude Code pricing আলাদা কোনো সাবস্ক্রিপশন নয়—আপনার ব্যক্তিগত Pro ($20/মাস), Max ($100/মাস) বা Ultra ($200/মাস) প্ল্যানের ভেতরেই টার্মিনাল, VS Code, Cursor ও JetBrains IDE-তে Claude Code ব্যবহারের সুবিধা যুক্ত থাকে। ৬ নভেম্বর ২০২৬-এর অফিসিয়াল হেল্প আপডেট অনুযায়ী, সীমা শেষ হলে এখন ১০% থেকে ৩০% ছাড়ে Usage Bundles ($50 বান্ডেল $45-এ, $250 বান্ডেল $200-এ এবং $1000 বান্ডেল $700-এ) কেনা যায়। সাধারণ Claude প্ল্যানের দাম জানতে Claude-এর দাম বাংলাদেশে দেখুন।

Claude Code pricing কীভাবে কাজ করে?

অনেক ডেভেলপার ভাবেন টার্মিনালে বা IDE-তে Claude Code চালাতে হলে শুরু থেকেই আলাদা API বিল দিতে হয়। Anthropic-এর অফিসিয়াল ডকুমেন্টেশন অনুযায়ী, ব্যক্তিগত ব্যবহারকারীরা তাঁদের Pro, Max বা Ultra সাবস্ক্রিপশন দিয়েই ওয়েব, ডেস্কটপ ও মোবাইল অ্যাপের পাশাপাশি টার্মিনাল এবং সমর্থিত IDE (VS Code, Cursor ও JetBrains)-তে Claude Code চালাতে পারেন।

সবচেয়ে গুরুত্বপূর্ণ নিয়ম হলো: আপনার সাবস্ক্রিপশনের ব্যবহারের সীমা (৫ ঘণ্টার সেশন লিমিট এবং সাপ্তাহিক লিমিট) claude.ai, Claude Desktop এবং Claude Code—সব জায়গায় একসঙ্গে গণনা হয়। অর্থাৎ চ্যাটে বড় ডকুমেন্ট বিশ্লেষণ করলে এবং একই সময়ে টার্মিনালে বড় রিপোজিটরি রিফ্যাক্টর করলে দুটিই একই বাজেট থেকে খরচ হবে। টার্মিনালে প্রথমবার সেটআপের ধাপ জানতে Claude Code বাংলা ডেভেলপার গাইড পড়ুন।

নতুন Usage Bundles ও অতিরিক্ত ব্যবহারের খরচ কত?

৬ নভেম্বর ২০২৬-এর অফিসিয়াল হেল্প ডকুমেন্ট অনুযায়ী, আপনার Pro, Max, Ultra বা Team প্ল্যানের নির্ধারিত সীমা শেষ হয়ে গেলে কাজ থামিয়ে রাখার দরকার নেই। আপনি চাইলে অগ্রিম Usage Bundles কিনে ১০% থেকে ৩০% পর্যন্ত সাশ্রয় করতে পারেন। এই ব্যালেন্স Claude, Claude Code, Claude Cowork এবং সমর্থিত থার্ড-পার্টি প্রোডাক্টে একসঙ্গে কাজ করে।

সতর্কতা

Max ($100), Ultra ($200) ও Team প্ল্যানে যে মাসিক Claude API ক্রেডিট দেওয়া হয়, তা কেবল Claude Console-এর API কলের জন্য। অফিসিয়াল নিয়ম অনুযায়ী, এই মাসিক API ক্রেডিট Claude Code বা চ্যাট অ্যাপের অতিরিক্ত ব্যবহারের (Usage credits) জন্য ব্যবহার করা যায় না।

সাবস্ক্রিপশন নাকি API Key — কোনটি ব্যবহার করবেন?

বাংলাদেশের ডেভেলপারদের সবচেয়ে বড় ভুল হয় কম্পিউটারে আগে থেকে সেট করা ANTHROPIC_API_KEY এনভায়রনমেন্ট ভ্যারিয়েবল নিয়ে। অফিসিয়াল হেল্প স্পষ্ট করে বলছে: আপনার সিস্টেমে যদি ANTHROPIC_API_KEY চালু থাকে, তবে Claude Code আপনার Pro বা Max সাবস্ক্রিপশন ব্যবহার না করে সরাসরি API ক্রেডিট থেকে টাকা কাটবে।

নিজের সাবস্ক্রিপশন প্ল্যান দিয়ে টার্মিনাল বা VS Code/Cursor-এ Claude Code চালাতে নিচের ধাপগুলো অনুসরণ করুন:

  1. টার্মিনালে আগে কোনো API সেশন বা ভুল অ্যাকাউন্ট লগইন থাকলে /logout কমান্ড দিয়ে পুরোপুরি বের হয়ে যান।
  2. আপনার শেল প্রোফাইল (~/.bashrc বা ~/.zshrc) থেকে ANTHROPIC_API_KEY মুছে ফেলুন বা আনসেট করুন।
  3. টার্মিনালে claude update চালিয়ে সর্বশেষ ভার্সনে আপডেট করুন এবং টার্মিনাল রিস্টার্ট করুন।
  4. এবার claude লিখে রান করুন এবং নিজের Pro, Max, Ultra বা Team অ্যাকাউন্ট নির্বাচন করে লগইন করুন।
  5. VS Code বা Cursor-এ এক্সটেনশন ব্যবহার করলে টার্মিনালের একই Claude অ্যাকাউন্ট দিয়ে সাইন ইন করুন।

বাংলাদেশ থেকে পেমেন্ট ও কার্ডের নিয়ম

Claude-এর সমর্থিত অঞ্চলের তালিকায় বাংলাদেশ আছে। ব্যক্তিগত Pro, Max ও Ultra প্ল্যান এবং Usage Bundles কেনার জন্য আন্তর্জাতিক লেনদেন (USD ই-কমার্স) চালু থাকা ভিসা বা মাস্টারকার্ড লাগে। সরাসরি bKash বা Nagad অপশন অফিসিয়াল চেকআউটে নেই; তবে বাংলাদেশি ব্যাংকের ডুয়াল-কারেন্সি কার্ড দিয়ে কীভাবে পেমেন্ট করবেন তা bKash দিয়ে AI tools কেনা ও Brac Bank Mastercard দিয়ে Claude সাবস্ক্রিপশন গাইডে বিস্তারিত পাবেন।

প্রতিদিন ছোট প্রজেক্ট বা শেখার কাজে Pro ($20) যথেষ্ট; কিন্তু বড় কোডবেসে সারাদিন এজেন্টিক কোডিং করলে Max ($100) বা ডিসকাউন্টেড Usage Bundle ছাড়া সেশন লিমিটে আটকে যাবেন।

  • নিজের কাজের পরিধি অনুযায়ী Pro ($20) নাকি Max ($100) লাগবে তা ৫ ঘণ্টার সেশন সীমা দিয়ে যাচাই করেছেন।
  • চেকআউট স্ক্রিনে ডলারের অঙ্ক, ভ্যাট/ট্যাক্স ও কার্ডের পাসপোর্ট এন্ডোর্সমেন্ট লিমিট দেখে নিয়েছেন।

সচরাচর জিজ্ঞাসা

Claude Code ব্যবহার করতে কি আলাদা সাবস্ক্রিপশন লাগে?

না। আপনার ব্যক্তিগত Pro ($20/মাস), Max ($100/মাস) বা Ultra ($200/মাস) এবং Team বা Enterprise সাবস্ক্রিপশনের ভেতরেই টার্মিনাল ও সমর্থিত IDE-তে Claude Code ব্যবহারের সুবিধা থাকে।

Claude Code-এর নতুন Usage Bundles কী?

পেইড প্ল্যানের নির্ধারিত সীমা শেষ হওয়ার পর কাজ চালিয়ে যেতে অগ্রিম ক্রেডিট বান্ডেল কেনা যায়। $50 বান্ডেল ১০% ছাড়ে $45-এ, $250 বান্ডেল ২০% ছাড়ে $200-এ এবং $1000 বান্ডেল ৩০% ছাড়ে $700-এ পাওয়া যায়।

Max বা Ultra প্ল্যানের ফ্রি API ক্রেডিট কি Claude Code-এ চলে?

না। অফিসিয়াল হেল্প অনুযায়ী, Max, Ultra ও Team প্ল্যানের মাসিক API ক্রেডিট কেবল Claude Console-এর API-তে কাজ করে; Claude Code বা চ্যাট অ্যাপের সাবস্ক্রিপশন ইউসেজে সেটি ব্যবহার করা যায় না।

VS Code বা Cursor-এ কি Claude Code চালানো যায়?

হ্যাঁ। VS Code, Cursor ও JetBrains IDE-তে অফিসিয়াল এক্সটেনশন ইনস্টল করে টার্মিনালের একই Claude অ্যাকাউন্ট দিয়ে লগইন করলে আপনার সাবস্ক্রিপশন প্ল্যানের সীমার ভেতরেই কাজ করবে।

সাবস্ক্রিপশন থাকার পরও API চার্জ কাটছে কেন?

কম্পিউটারে ANTHROPIC_API_KEY এনভায়রনমেন্ট ভ্যারিয়েবল সেট করা থাকলে Claude Code সাবস্ক্রিপশনের বদলে API কী ব্যবহার করে। টার্মিনালে সেটি আনসেট করে /logout দিয়ে পুনরায় নিজের অ্যাকাউন্টে লগইন করুন।
