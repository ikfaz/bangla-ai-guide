প্রকাশিত: ২৪ মার্চ, ২০২৬

আদনান সিদ্দিকী NSU-এর CSE-র শেষ semester-এর ছাত্র, ২০২৬-এ graduate হবেন। তাঁর ১ম-attempt-এ Grameenphone Digital Engineer trainee position-এ shortlist হয়নি। ২য়-attempt Unilever Marketing Trainee-তেও না। তিনটা rejection-এর পর তিনি ATS audit করালেন একজন career consultant-এর সঙ্গে — এবং discovery devastating: তাঁর CV-এর ATS score ৩৪% (নিরাপদ threshold ৭৫%)। তাঁর CV-তে graphics, columns, photo — সব ATS-unfriendly elements ছিল, এবং keyword match ১২ requirements-এর মধ্যে ৩টা। ১৪ দিন পর তিনি একটা new CV বানালেন — AI-augmented workflow-এ। সেই CV-এর ATS score ৯২%। পরবর্তী ৬টা application-এ ৫টা interview call। আজ তিনি Robi Axiata-র Software Engineer trainee — joining offer ৭২,০০০ starting। তাঁর CV বদল-এ ১৪ দিন, career trajectory ৫ বছর। সেই workflow-ই এই article-এ।

"AI দিয়ে CV বানিয়ে নাও" — generic advice। কিন্তু ২০২৬-এ AI-detected CV রেজেক্ট-পথে যায় ৬০% সময়। সঠিক উপায়: AI structure/keyword optimize করে, content-এ আপনার specific achievements এবং numbers। এই article সেই hybrid playbook + ৫টা real tool comparison + BD-specific ATS reality।

ATS reality — যা না জানলে CV লেখার মানে নেই

Applicant Tracking System একটা software যা ১,০০০+ application-এর CV scan করে keyword + structure-এর basis-এ rank করে। মানব recruiter দেখার আগে CV ATS-এর gauntlet পার হয়। বাংলাদেশের ২০২৬-এর reality:

  • Deployed at: Grameenphone, Robi, Banglalink, Unilever, BAT, Nestlé, BRAC Bank, City Bank, Eastern Bank, ICCB Bank, Square, Beximco, Pathao, Chaldal, bKash।
  • Most-used ATS platforms: Workday, Greenhouse, Lever, Bdjobs internal ATS।
  • Top 30% applications-এ recruiter spend দেয় ~৬ সেকেন্ড। বাকি ৭০% manually দেখাও হয় না।
  • Common ATS-killing CV elements: Tables, columns, graphics, photos, fancy fonts (anything non-Arial/Calibri/Times), header-footer text, watermark।

আদনানের ১৪-দিন pivot — exact workflow

Day 1-2: Job description audit

আদনান target করছিলেন Software Engineer trainee positions। ১৫টা actual recent JD (Bdjobs, LinkedIn) collect করে ChatGPT-এ:

"নিচের ১৫টা BD Software Engineer trainee JD-তে যেগুলো keyword সবচেয়ে বেশি repeat হয়েছে, সেগুলোর frequency-sorted list দাও। Generic terms (communication, teamwork) skip, technical specific (Python, SQL, REST API, Git, Agile) priority। Top 30 keywords।"

Result: তাঁর target keyword cluster — যেগুলো তাঁর CV-তে অবধারিত থাকতে হবে। তাঁর old CV-তে ৩০ এর মধ্যে ৩টা ছিল।

Day 3-5: Master CV rebuild

Tool: Claude Sonnet 4.6 (writing quality), Google Docs (final formatting)। Single column, Arial 10pt body / 12pt heading, no graphics, no photo।

আদনানের Claude prompt:

"আমার current CV নিচে paste করছি। এটার ATS-friendly version বানাও, যেখানে: (১) Single column, no table/graphic, (২) প্রতি bullet point action-verb দিয়ে শুরু (Led, Designed, Implemented, Optimized), (৩) প্রতি bullet-এ একটা measurable result/number, (৪) target job-এর top-30 keyword (নিচে list করছি) natural inject (৫-৭টা places), (৫) Professional Summary ৩-৪ sentence, target position-এ tailored।"

Day 6-7: Numbers + specificity inject

Claude-এর output-এ generic numbers ("improved performance by 30%") ছিল। আদনান নিজে actual data fill করেছেন: "Reduced API response time from 850ms to 320ms by implementing Redis caching for the e-commerce checkout flow (university project, GitHub link)।" Specific, verifiable, interview-friendly।

Day 8-10: ATS scoring + iteration

৩টা free ATS scorer-এ test:

  • Resumeworded.com: Detailed score breakdown (search optimization, layout, content)।
  • Jobscan.co: Per-job match score with specific keyword gap।
  • VMock.com: AI-driven feedback on language strength।

প্রতি iteration-এর পর score check। ৩ iteration-এ আদনানের score ৩৪% → ৭৮% → ৮৬% → ৯২%।

Day 11-12: Per-application tailoring

Master CV ready। কিন্তু প্রতি application-এ tailor। Workflow: New JD এসেছে → Claude-এ paste master CV + new JD → "এই JD-এর top requirements-এ ১২টা bullet হতে হবে। আমার master CV-এর কোন বুলেট কে keep, কোনগুলো replace by what — exact suggest করো।" ১৫ মিনিটে tailored 1-page CV।

Day 13-14: Cover letter system

আদনান একটা template বানিয়েছিলেন যা Claude-এ-ই reusable। ৪-paragraph formula:

  • Para 1 (hook): Company-specific news/launch reference।
  • Para 2 (proof): One specific achievement mapping JD's #1 requirement।
  • Para 3 (gap bridge): Self-aware skill-building signal।
  • Para 4 (close): Specific time/availability offer।

BD-তে সেরা ৫টা AI Resume tool — actual comparison

  • Claude Pro/Free: Best for writing quality। আদনানের choice। Free tier daily limited but enough for CV iteration। No template — Google Docs-এ manual format।
  • ChatGPT Plus + Custom GPT "Resume Optimizer": Convenient। Plus-এ Custom GPT use-readily। Voice quality slightly less natural than Claude।
  • Teal HQ (teal.com): Free tier excellent। Per-job tailoring, ATS scoring built-in। Best dedicated tool।
  • Kickresume: Template-rich, AI-assisted। $7/month। বাংলা UI নেই।
  • Resumeworded.com: Scoring + LinkedIn audit। বেস্ট স্কোরিং tool। Free tier 2 scans/month।

BD job categories-এ specific CV strategy

  • Banking/Finance MT (BRAC, Eastern, City): CGPA strict (≥3.50)। Math/aptitude-friendly background highlight। CA articleship/CFA Level-1 mention।
  • Tech (bKash, Pathao, Chaldal): GitHub link mandatory। Real projects > certificates। Stack proficiency specific (React, Node, PostgreSQL, AWS)।
  • MNC (Unilever, BAT, Nestlé): Aptitude + GD round। CV-তে leadership signal critical।
  • RMG (Beximco, Square, DBL): Buyer communication experience, fabric/costing technical।
  • NGO (BRAC, CARE): Mission alignment signal। Volunteer + donor-language familiarity।
  • Government (BCS/non-cadre): Separate strict format। BPSC-এর format mandatory।

৫টা common mistake — যেগুলো ৮৫% BD candidate করেন

  • 1. Photo on CV: বাংলাদেশের traditional CV-তে photo standard, কিন্তু MNC ATS-এ instant disadvantage। MNC apply-এ photo skip।
  • 2. Same CV for every job: 1 master CV → tailored variants per application। Mass-apply-এ tailored CV ১৫ মিনিট, কিন্তু response rate ৪×।
  • 3. Generic "objective": "Looking for a challenging position..." instant skip। Replace with specific Professional Summary tied to JD।
  • 4. Action verb missing: "Was responsible for marketing campaigns" → "Led marketing campaigns generating ৳৮ লাখ revenue in Q2 FY25"।
  • 5. No measurable result: Every bullet should have a number, %, currency, time-saved, or scale (team of N, X countries, Y users)।

LinkedIn — CV-এর invisible companion

BD MNC recruiters প্রতি shortlisted candidate-এর LinkedIn check করেন। CV ≠ LinkedIn হলে red flag। আদনানের সমন্বয়িত workflow:

  • Headline (220 char): "Aspiring Software Engineer | Building scalable backend systems with Python & Node.js | CSE @ NSU '26"
  • About (2,600 char): 3-paragraph: who-you-are, what-you-have-done, where-you-are-going। AI-augmented draft + own voice rewrite।
  • Experience: Mirror your CV bullets, slightly more conversational।
  • Skills: Endorsement game — top 5 skills aligned to target role।

উপসংহার — আপনার আজকের পদক্ষেপ

আদনান বলেন: "১ম-attempt-এ আমি ভাবিনি CV-ই সমস্যা। ভাবতাম my CGPA, my skills কম। ATS audit করার পর realize করি — আমার technical skill সঠিক ছিল, কিন্তু আমার CV ATS-এর কাছে invisible ছিল। ১৪ দিনের CV বদল আমার career-এর প্রথম ৫ বছর বদলেছে।" আজই করুন: (১) আপনার current CV-এর ATS score পরীক্ষা করুন Resumeworded.com বা Jobscan-এ (free), (২) আপনার target career-এর ৫টা recent JD থেকে Claude/ChatGPT দিয়ে keyword cluster extract করুন, (৩) ১৪-দিনের আদনান-workflow apply করুন। তিন সপ্তাহ পর আপনার পরবর্তী application-এ আপনি যে interview call পাবেন — সেটাই আপনার measure।

প্রায়শই জিজ্ঞাসিত প্রশ্ন (FAQ)

AI দিয়ে CV তৈরি করা কি ঠিক?

হ্যাঁ, AI দিয়ে CV তৈরি করা সম্পূর্ণ গ্রহণযোগ্য। তবে AI-এর আউটপুট সরাসরি ব্যবহার না করে নিজের ভাষায় সম্পাদনা করুন এবং তথ্যের সত্যতা যাচাই করুন।

ফ্রিতে সেরা AI CV মেকার কোনটি?

ChatGPT ফ্রি দিয়ে CV কন্টেন্ট লিখে Canva ফ্রি তে ডিজাইন করা সবচেয়ে ভালো ফ্রি অপশন। ফ্রি AI টুলস ২০২৬ গাইডে আরও টুল দেখুন।

ATS কী এবং কেন গুরুত্বপূর্ণ?

ATS (Applicant Tracking System) হলো সফটওয়্যার যা কোম্পানিগুলো CV ফিল্টার করতে ব্যবহার করে। বাংলাদেশের Grameenphone, Unilever, BRAC এর মতো প্রতিষ্ঠান এটি ব্যবহার করে।

CV তে কি ছবি দেওয়া উচিত?

আন্তর্জাতিক প্রতিষ্ঠান ও ATS সিস্টেমে ছবি না দেওয়াই ভালো। তবে বাংলাদেশের স্থানীয় কোম্পানি ও ব্যাংকে CV তে ছবি দেওয়ার প্রচলন আছে — সেক্ষেত্রে প্রফেশনাল ছবি দিন।
