ভূমিকা — তাসনিম-এর Brac Mastercard + Claude journey

তাসনিম Singapore-এ থাকলেও তার primary card Bangladesh-এর Brac Bank Platinum Mastercard। কারণ — Singapore card-এ Bangladesh address verification fail হতো, আর parents-এর সাথে account linked থাকায় Brac-এ trust + history দুটোই strong। ২০২৪-এর শেষ থেকে তিনি Claude Pro use করছেন coding + technical document writing-এর জন্য। ২০২৬-এর শুরুতে Claude Max-ও যোগ করেছেন — Opus 4.7-এর unlimited access-এর জন্য।

"আমি Surbana Jurong-এ structural engineer। দিনে গড়ে ৬-৮ ঘণ্টা Claude use করি — calculation review, code generation (Python script for FEA), client report writing। Pro $20-এ কুলায় না — Max লাগেই। তাই Brac Platinum-এ $120/মাস auto-debit setup," তাসনিম explain করেন। কিন্তু এই smooth setup-এ পৌঁছাতে তাকে ৩-৪ বার rejection, ২ বার USD limit issue, একবার 3D Secure failure face করতে হয়েছিল।

USD endorsement — Brac Bank-এর rule + paperwork

Bangladesh Bank-এর rule অনুযায়ী, প্রতিটি international card-এ USD use করতে হলে separate endorsement লাগে। Brac Bank-এ default endorsement $1,200/বছর — এটাই সবচেয়ে common limit, এতে travel + small subscription manage করা যায়। কিন্তু $120/মাস Claude combo মানে $1,440/বছর — default-এর বাইরে। তাই endorsement বাড়াতে হবে।

  • Default endorsement: $1,200/বছর — automatic, কোনো paperwork ছাড়াই।
  • $5,000+ endorsement: Salary certificate বা bank statement + TIN copy লাগে।
  • Renewal: প্রতি বছর January-এ reset, manually monitor করতে হয়।
  • Application process: Brac Bank branch-এ form fill করতে হয় বা online banking থেকে request পাঠানো যায়।
  • Processing time: ৩-৭ working day।
তাসনিম-এর tip: "আমি Singapore-এ থেকে Brac branch-এ যাওয়া possible না। তাই online banking app থেকে endorsement request পাঠাই — salary certificate-এর scanned copy + Singapore-এর employment letter upload করি। ৫ দিনে $6,000/বছর limit confirm হয়। এতে Claude + ChatGPT + GitHub Copilot — সব cover।"

Step-by-step setup — Brac online banking + USD activation + Claude.ai signup

সব paperwork ready থাকলে Claude subscription কেনা সরাসরি ১৫-২০ মিনিটের কাজ। তাসনিম-এর exact workflow:

  • Step 1 — Brac Bank app login: Astha (Brac Bank-এর official app) install করুন। Login PIN + biometric set করুন।
  • Step 2 — Card USD activation check: "Cards" section-এ গিয়ে আপনার Mastercard select করুন। "International Transaction" toggle ON থাকতে হবে। OFF থাকলে enable করুন।
  • Step 3 — USD limit verify: Same screen-এ "Available USD endorsement" দেখুন। যদি $120-এর কম থাকে তাহলে অপেক্ষা করুন বা endorsement বাড়ান।
  • Step 4 — Claude.ai signup: claude.ai-এ যান, Gmail বা separate email দিয়ে account খুলুন। Email verification complete করুন।
  • Step 5 — Upgrade to Pro: Settings → Billing → Upgrade to Pro। Stripe payment screen আসবে।
  • Step 6 — Card details enter: Brac Platinum Mastercard number, expiry, CVV, name দিন। Billing address হিসেবে আপনার ঢাকার address — same as Brac Bank-এ registered address।
  • Step 7 — 3D Secure OTP: Brac Bank থেকে SMS-এ OTP আসবে। Astha app-এও notification আসতে পারে। ৬-digit OTP enter করুন।
  • Step 8 — Subscription confirm: Successful charge হলে immediate Pro access। Email-এ receipt আসবে।
  • Step 9 — Max add (optional): Pro active হওয়ার পর "Upgrade to Max" option। Same card use করুন।

Common rejection reasons + specific fix

তাসনিম-এর প্রথম ৩-৪ rejection-এর exact reason + fix — যাতে আপনাকে একই trial-error না করতে হয়।

  • Reason 1 — International transaction OFF: Default-এ Brac card-এ international transaction OFF থাকে। Astha app-এ ON করুন।
  • Reason 2 — USD endorsement exhausted: Year-শেষে limit শেষ হয়ে যেতে পারে। Brac Bank থেকে check করুন কত balance আছে। কম হলে endorsement বাড়ান।
  • Reason 3 — 3D Secure (OTP) timeout: OTP ৩ মিনিটে expire হয়। দেরি করলে fail। Astha notification + SMS দুটোই enable রাখুন।
  • Reason 4 — Billing address mismatch: Claude-এ enter করা address Brac Bank-এ registered address-এর সাথে exact match হতে হবে। শব্দান্তর-এ মিল না থাকলে decline।
  • Reason 5 — Card BIN block by Anthropic: খুব rare, কিন্তু কখনো Stripe কিছু BD card BIN flag করে। সেক্ষেত্রে Anthropic support-এ email করুন, অথবা different Brac card try করুন।
তাসনিম-এর rejection story: "প্রথমবার Pro upgrade-এ Platinum card decline হলো। Reason — international transaction OFF ছিল। Astha-এ ON করলাম, আবার try করলাম — fail আবার। এবার reason — billing address-এ আমি "House 12, Road 5, Dhanmondi" লিখেছিলাম, কিন্তু Brac Bank-এ registered ছিল "12/A, Road 5/B, Dhanmondi"। Exact match correction করার পর ৩ মিনিটে success। তখন বুঝলাম — Stripe + Brac Bank AVS (Address Verification System) খুব strict।"

Claude Pro vs Max — কোনটা কাকে উপযুক্ত

সবার Max লাগে না। তাসনিম-এর use case-এ Max justify হয়, কিন্তু সাধারণ user-এর জন্য Pro যথেষ্ট।

  • Claude Pro ($20/মাস): Sonnet 4.6 unlimited + Opus 4.7 limited (5x free user-এর rate)। Casual user, student, content writer, occasional coder-এর জন্য enough।
  • Claude Max ($100/মাস): Pro-এর সব + Opus 4.7 5x higher rate। Power user — daily 8+ hour Claude use করেন এমন professional-এর জন্য।
  • Claude Max ($200/মাস): 20x higher rate। Heavy developer, agency owner, AI-first business-এর জন্য।
  • Pro + Max combo: তাসনিম-এর মত পেশাদার-যারা separate workflows আলাদা করতে চান।

BD billing address requirement + workaround

Claude.ai billing-এ country detection automatic — card BIN দেখে Bangladesh detect করে। কিন্তু address field-এ exact Brac Bank registered address দিতে হবে — AVS check fail হলে instant decline।

  • Brac Bank registered address verify: Astha app → Profile → Permanent Address দেখুন।
  • Claude billing address field: Same English transliteration-এ লিখুন। উদাহরণ — "House 12/A, Road 5/B, Dhanmondi, Dhaka 1209, Bangladesh"।
  • Workaround for address mismatch: Brac branch-এ গিয়ে address update করুন, তারপর Claude-এ retry।
  • Probashi (NRB) workaround: তাসনিম-এর মত abroad থাকলে — Brac NRB hotline (+880-2-988-3779) call করে address sync করুন।

Refund + dispute process (Brac Bank দিয়ে)

Anthropic refund policy — pro-rated refund দেয় না, কিন্তু accidentally double charge বা service unavailability-এর ক্ষেত্রে refund process করে। Brac Bank-এর side থেকেও dispute initiate করা যায়।

  • First step — Anthropic support: support.anthropic.com-এ ticket open করুন। Issue description + transaction date + amount দিন।
  • Response time: Anthropic সাধারণত ৪৮-৭২ ঘণ্টায় respond করে।
  • Brac Bank chargeback: Anthropic respond না করলে বা refuse করলে — Brac Bank-এ chargeback request করুন। Astha app → Disputes → New Dispute।
  • Documentation: Anthropic-এর সাথে communication screenshot + transaction proof আপলোড করতে হবে।
  • Processing time: Brac Bank chargeback ৩০-৪৫ দিনে resolve হয়।

Alternative scenarios — Brac না হলে City/EBL/DBBL

Brac Bank account না থাকলেও সমস্যা নেই। অন্যান্য BD bank-এও similar Mastercard option আছে। তবে প্রতিটি bank-এর specific quirk আছে।

  • City Bank American Express + Mastercard: Amex Platinum Bangladesh-এ সবচেয়ে premium, কিন্তু Claude/Anthropic অনেক সময় Amex accept করে না — Mastercard variant নিন।
  • EBL Aqua Mastercard: Eastern Bank Limited-এর primary international card। USD endorsement easy, Claude-এ smoothly work করে।
  • DBBL Nexus Mastercard: Dutch-Bangla Bank-এর entry-level option। $500-$1,000 limit। Pro-এর জন্য enough, Max-এর জন্য কঠিন।
  • Standard Chartered Visa Platinum: Mastercard না হলেও Claude Visa accept করে। SC-এর premium customer-এর জন্য option।
  • HSBC Premier Mastercard: Bangladesh-এ limited customer base, কিন্তু international transaction-এ smoothest।

সীমাবদ্ধতা + customer support contact

Brac Bank Mastercard-এর কিছু practical limitation যা জেনে রাখা ভালো:

  • Forex conversion charge: 2-2.5% per transaction। $20 charge-এ ~$0.50 extra।
  • USD endorsement renewable: প্রতি বছর January-এ reset, monitor করতে হবে।
  • 3D Secure (OTP) mandatory: Bangladesh Bank-এর rule, bypass সম্ভব না।
  • Astha app dependency: International transaction toggle, OTP — সবকিছু app-এ। App update পরিবর্তে banking issue হতে পারে।
  • Brac Bank Contact Center: 16221 (Bangladesh থেকে) বা +880-2-988-3779 (NRB hotline)।
  • Anthropic billing support: support.anthropic.com — billing-specific query-তে ৪৮-৭২ ঘণ্টা response time।

উপসংহার — আপনার আজকের পদক্ষেপ

Brac Bank Mastercard বাংলাদেশে Claude subscription-এর জন্য সবচেয়ে reliable option-গুলোর একটি, বিশেষ করে Platinum + World variant। তাসনিম-এর journey দেখায় — প্রথম-এ rejection হবে, কিন্তু international transaction toggle, USD endorsement, exact billing address — এই তিনটা ঠিক থাকলে setup দীর্ঘমেয়াদে smooth। যদি আপনি Brac customer হন, আজই Astha app-এ international transaction ON করুন, USD endorsement balance check করুন, তারপর claude.ai-এ free account থেকে Pro upgrade try করুন। প্রথমবার fail হলে rejection reason জানতে Brac 16221-এ call করুন — বেশিরভাগ ক্ষেত্রে একটাই tweak লাগে।
