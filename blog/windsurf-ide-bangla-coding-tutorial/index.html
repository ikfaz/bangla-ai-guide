মূল feature — Cascade

Cursor-এর Composer-এর সঙ্গে Cascade-এর তুলনা inevitable, কিন্তু পার্থক্য আছে:

  • Multi-file aware: Cascade একটা task নিয়ে whole repo scan করে, dependency graph বানায়।
  • Plan + execute pattern: First plan show করে, approve করার পর execute। Hallucination কম।
  • Long task durability: ১-৩ ঘণ্টার task হ্যান্ডল করে disconnect ছাড়া।
  • Test-aware: Code edit-এর সঙ্গে existing test run + fail হলে fix attempt।
  • Terminal integration: Cascade নিজে terminal command run করতে পারে — package install, test run, build।

Install — Windows/Mac/Linux

  • Linux: .deb (Ubuntu/Debian) বা .AppImage

প্রথম project-এ practical workflow (Faruk-এর pattern)

  1. Project open: Windsurf launch → "Open Folder" → existing repo।
  2. Index wait: প্রথমবার Windsurf whole codebase index করে (১-৩ মিনিট ৫০K লাইনের জন্য)। তারপর context-aware।
  3. Daily inline edit: Code select → Cmd+I → instruction। যেমন: "Add try-catch with Bangla error message।"
  4. Multi-file task: Cmd+L → Cascade open। "এই feature এই ৫টা file জুড়ে add কর" → plan show, approve, execute।
  5. Codebase chat: Right sidebar chat-এ "@codebase auth flow explain" — repo-aware answer।
  6. Long task: Big refactor-এ Cascade Flow on → Faruk lunch break-এ যান, return-এ review।
