Stable Diffusion বাংলা ইনস্টল গাইড — নিজের কম্পিউটারে Local AI Image

ই
ইকফাজ প্রতিষ্ঠাতা ও সম্পাদক

বাংলা AI গাইডের প্রতিষ্ঠাতা। বাংলাদেশি ব্যবহারকারীদের জন্য AI টুলস কিউরেট ও বিশ্লেষণ করেন — কোনটা BD থেকে কাজ করে, কোনটায় bKash চলে, কোনটা আসলে দৈনন্দিন কাজে লাগে।

প্রকাশিত: ২৬ মে, ২০২৬

কেন Local Stable Diffusion?

  • Unlimited generation — Midjourney/DALL-E subscription bypass
  • Privacy — ছবি cloud-এ যায় না
  • Custom model — Civitai থেকে হাজারো checkpoint
  • NSFW filter free — শিল্পচর্চার সীমাহীনতা
  • Offline ব্যবহার — internet ছাড়া কাজ করে

হার্ডওয়্যার minimum

  • GPU: NVIDIA RTX 3060 (১২GB VRAM) বা better; AMD সম্ভব কিন্তু slow
  • RAM: ১৬GB+
  • Disk: ৫০GB+ free (model files বড়)
  • Mac: M1/M2/M3 চলে কিন্তু slower

Automatic1111 (সবচেয়ে popular) — Windows-এ install

  • Python 3.10.6 install (anaconda না — clean install)
  • Git install
  • CMD: git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui
  • Folder-এ যান, webui-user.bat double-click — auto-install শুরু
  • প্রথম run-এ ২-৩GB model download
  • Browser-এ http://127.0.0.1:7860 open
  • Prompt লিখুন, "Generate" — হয়ে গেছে!

ComfyUI (advanced workflow)

  • Node-based interface — power user-দের জন্য
  • Automatic1111-এর চেয়ে দ্রুত এবং memory-efficient
  • GitHub: comfyanonymous/ComfyUI
  • Custom workflow JSON share করা যায়

Model download — Civitai

  • civitai.com — হাজারো community model (anime, realistic, art style)
  • Top picks: SDXL, Realistic Vision, DreamShaper, AnimagineXL
  • .safetensors ফাইল ডাউনলোড করে models/Stable-diffusion folder-এ paste
  • Refresh — Web UI-তে দেখাবে

বাংলাদেশি ব্যবহারকারীদের জন্য টিপস

  • GPU না থাকলে — Google Colab-এ free run করা যায় (limited)
  • Daraz-এ used RTX 3060/3070 ৪০-৬০ হাজার টাকার মধ্যে পাওয়া যায়
  • বাংলা prompt না — ইংরেজিতে লিখুন (SD বাংলা train না)
  • Negative prompt গুরুত্বপূর্ণ: "blurry, low quality, bad anatomy"

সাধারণ সমস্যা

  • "CUDA out of memory" → batch size কমান, resolution কমান
  • "Black image" → VAE check, half precision setting
  • Slow generation → --xformers flag enable

উপসংহার

Local Stable Diffusion একবার setup করলে আপনার AI image budget শূন্যে নামবে। GPU থাকলে — এই সপ্তাহান্তে install করুন। প্রথমে frustrating মনে হবে, কিন্তু এক মাস practice-এ Midjourney quality output পাবেন।
