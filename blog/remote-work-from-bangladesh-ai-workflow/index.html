ভূমিকা — Fahim-এর Plaid Remote Work Journey

২০১৬-তে BUET CSE পাস করে Fahim প্রথমে Pathao-তে Backend Engineer হিসেবে join করেন (৳৪৫,০০০/মাস)। ২০১৯-এ Grameenphone-এ shift (৳৯০,০০০)। ২০২১-এ COVID period-এ LinkedIn-এ Plaid-এর "Remote Backend Engineer (worldwide)" posting দেখে apply। তিন রাউন্ড interview — system design, Go coding, behavioral। ২০২২ January-তে $5,800/mo offer + ESOP।

প্রথম ছয় মাস কঠিন ছিল। US EST timezone-এ team standup রাত ৮টায়। code review feedback আসত সকাল ৪টায়। সপ্তাহে ৪ দিন late-night call। ২০২৪ মাঝামাঝি Claude Code launch হবার পর Fahim async workflow restructure করলেন। ২০২৫-এ Senior promotion ($7,200)। ২০২৬-এ Plaid Bangladesh থেকে আরো ৩ জন hire করেছে — Fahim-এর referral-এ।

BD Remote Work Landscape — Opportunities + Challenges

২০২৬-এ BD remote work scene পাঁচ বছরের তুলনায় অনেক বদলেছে। আগে শুধু Upwork gig ছিল; এখন full-time worldwide-remote position commonplace।

  • Top platforms (৳ rate ascending): Fiverr → Upwork → Freelancer.com → Toptal → LinkedIn jobs → AngelList/Wellfound → company direct।
  • BD থেকে hire করে এমন remote-friendly companies: Vercel, Plaid, Coinbase, Bolt, ShareTrip, Gitlab, Automattic, Doist, Buffer।
  • Hot roles ২০২৬: Backend (Go, Rust, Python), DevOps/SRE, AI/ML engineer, technical writer, product designer, customer success (US হাব overlap)।
  • Salary band: Junior freelancer $৫-১৫/hour, Mid-level contract $২৫-৬০/hour, Senior FAANG remote $৫,০০০-১২,০০০/mo।
  • Challenges: Internet outage (load shedding), Wise BD account challenge, withdrawal limits, timezone fatigue, isolation।

Time-Zone Management AI (Calendar + Meeting Prep)

BD GMT+6। US EST সাথে ১১ ঘণ্টা পিছিয়ে — overlap শুধু সন্ধ্যা ৭টা থেকে ১১টা। UK GMT সাথে ৬ ঘণ্টা — সকালে overlap। Fahim-এর Plaid team San Francisco-তে (PST) — overlap রাত ১০টা থেকে ভোর ১টা।

AI ছাড়া এই schedule unsustainable। Fahim Reclaim.ai + ChatGPT + Calendly দিয়ে কী করেন:

  • Reclaim.ai auto-schedule: "Deep work" block সকাল ১০টা-দুপুর ২টা; meeting শুধু সন্ধ্যা ৭টা-১০টা।
  • ChatGPT meeting prep: Calendar invite forward → ১৫ মিনিটে briefing (attendees, prior threads, agenda hypothesis)।
  • Claude Projects "context vault": প্রতিটি teammate-এর working style, timezone, past disagreement — persistent memory।
  • Calendly multi-zone link: Client নিজের timezone-এ slot দেখেন; double-booking impossible।
  • Otter.ai live transcribe: ক্লান্ত state-এ call missed হলেও transcript + AI summary সকালে।

Async Communication AI — Loom + Notion + Slack + ChatGPT Summaries

Remote work-এর gold rule: "If it can be async, it must be async." Fahim-এর Plaid team-এ ১৫ জন; ৪ continent-এ ছড়ানো। Synchronous call শুধু sprint planning (সপ্তাহে ১) + 1:1 (সপ্তাহে ১)।

  • Loom + AI summary: ৫ মিনিটের video → Loom AI ৩ paragraph + action items extract করে।
  • Notion AI for PR description: "diff paste + write reviewer-friendly summary" — ২ মিনিটে publishable।
  • Slack ChatGPT thread digest: ১০০-message channel scroll → ChatGPT "summarize last 24h"।
  • Claude Code commit message: staged diff থেকে conventional commit message — manual writing eliminated।
  • Granola for meetings: Live meeting notes + AI-generated follow-up email draft।
Fahim's golden rule: "প্রতিটি sync meeting-এর আগে নিজেকে জিজ্ঞেস করি — এই info কি Loom + Notion দিয়ে async কাজ হবে? ৮০% সময় উত্তর হ্যাঁ।"

Client Communication — Proposal, Contract, Status Update AI

BD freelancer-এর সবচেয়ে বড় bottleneck — English writing + cultural nuance। US client-এর সাথে "I will do this" এবং "I'd be happy to take this on" — দ্বিতীয়টা ৩x more likely to win।

  • Proposal writing: Claude-এ "Write Upwork proposal for [JD paste], my profile [link]। Tone: confident, specific, ৩০০ words max."
  • Contract review: ChatGPT-এ NDA/MSA upload → "Flag any clause unfair to contractor in BD jurisdiction।"
  • Weekly status update: Fahim-এর Friday template — Linear ticket export → Claude → 1-paragraph exec summary + 3-bullet next week।
  • Difficult conversation: Salary negotiation, scope creep pushback — Claude-এ role-play first।
  • Voice tone match: Client-এর past email paste → "match this tone for my reply।"

Payment + USD Handling — Wise, Payoneer, Brac Mastercard, NBR Tax

২০২৬-এও BD-তে USD inward সবচেয়ে friction-heavy step। Bangladesh Bank-এর rule: USD income শুধু authorized dealer bank দিয়ে আসতে হবে।

  • Wise: BD personal account ২০২৪ থেকে restricted; business account সম্ভব trade license + TIN দিয়ে। অনেকের জন্য workaround।
  • Payoneer: Upwork-এর default। মাসিক withdraw limit ~$১০,০০০। Brac/EBL-এ BDT-তে আসে।
  • Brac Bank Tara Mastercard / Tara World: USD income receive + spend — Plaid-এর মতো full-time employee-দের জন্য ideal।
  • EBL / SCB / Citi NA: USD ERQ account allowed; ৭০% retain করা যায় USD-তে, ৩০% BDT conversion mandatory।
  • NBR tax reality: "Freelance income 0% tax" — এটি myth। Actual rule: gross income annual ৩ লক্ষ-এর উপরে professional income হিসেবে taxable (15-25% slab)। তবে IT/ITES export earning-এ rebate; Fahim-এর CA বছরে effective ~৬-৮% pay করেন।
  • TIN + return filing: বার্ষিক mandatory; freelance income hide করা = future visa application risk।
Practical tip: Fahim প্রতি মাসে salary received-এর ১০% আলাদা USD savings-এ রাখেন (NBR tax + emergency)। CA Mr. Hossain (Gulshan) বার্ষিক ৳২৫,০০০-এ return file করেন।

Career Progression — Promotion Negotiation, Salary Benchmark AI

Remote job-এ "out of sight, out of mind" risk আছে। Promotion + raise negotiate করার জন্য proactive থাকা mandatory।

  • Levels.fyi + Glassdoor: Yearly salary benchmark; same level US-based পেলে কত পেত।
  • Claude promotion document: ১২ মাসের Linear ticket + PR + client feedback paste → "Write promotion case in PIE framework (Performance, Image, Exposure)।"
  • 1:1 prep: Manager-এর সাথে call-এর আগে ChatGPT-এ practice — objection handling।
  • Visible work via LinkedIn: সপ্তাহে ১ post — Claude assist করে; recruiter ping increase করে।
  • Conference talk / blog: Fahim ২০২৫-এ GopherCon-এ talk দিয়েছিলেন; raise negotiation-এ leverage হয়েছিল।

Common Mistakes BD Remote Workers Make

  • Over-promising delivery: "কাল দিয়ে দিচ্ছি" বলে ৩ দিন late। Claude estimate দিয়ে realistic timeline দিন।
  • Email-এ "Sir/Madam": US client-এর কাছে old-fashioned। "Hi [first name]" standard।
  • Sync call-এ over-reliance: অপ্রয়োজনীয় meeting accept করা — async first।
  • Tax hide করা: ৫-১০ বছর পর US visa, mortgage, MBA application-এ banking history audit হয়। TIN + return mandatory।
  • One client dependency: ৮০% income এক client থেকে আসলে — relationship তিক্ত হলে disaster। ২-৩ client diversify।
  • Imposter syndrome: "আমি Indian/US developer-এর সমান না" — fact: BD top ১০% engineer global market-এ competitive।
  • Cheap rate quote: Junior phase-এ $৫/hour নিলে মান্থ-এর পরও তা cap হয়ে যায়। ৬ মাস পর rate বাড়ান।
  • Internet/electricity backup নেই: মিনিমাম ৪G dongle + IPS/UPS — call drop = client trust drop।

উপসংহার — আপনার আজকের পদক্ষেপ
