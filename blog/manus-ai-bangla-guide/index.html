Manus AI বাংলা গাইড — অটোনোমাস AI এজেন্ট কী, কীভাবে কাজ করে?

ই
ইকফাজ প্রতিষ্ঠাতা ও সম্পাদক

বাংলা AI গাইডের প্রতিষ্ঠাতা। বাংলাদেশি ব্যবহারকারীদের জন্য AI টুলস কিউরেট ও বিশ্লেষণ করেন — কোনটা BD থেকে কাজ করে, কোনটায় bKash চলে, কোনটা আসলে দৈনন্দিন কাজে লাগে।

প্রকাশিত: ২৬ মে, ২০২৬

ভূমিকা — Manus কী?

Manus AI ২০২৫ সালের মাঝামাঝি launch হয়ে AI দুনিয়ার দ্রুত-বর্ধমান ক্ষেত্রটি — "autonomous AI agent" — কে populariz করেছে। সাধারণ ChatGPT যেখানে প্রশ্ন-উত্তরে সীমাবদ্ধ, Manus সেখানে নিজে নিজেই ওয়েবসাইট ভিজিট করে, ফাইল বানায়, কোড লেখে, এমনকি অর্ডারও দিতে পারে।

এক বাক্যে: Manus হলো একজন AI কর্মী যাকে আপনি কাজ assign করেন, ও সম্পূর্ণ কাজ delivery করে।

Manus সাধারণ chatbot থেকে কীভাবে আলাদা?

  • ChatGPT/Claude: উত্তর দেয় টেক্সটে — আপনি copy/execute করেন
  • Manus: নিজে browser চালায়, code execute করে, file save করে, multi-step plan auto-execute করে
  • উদাহরণ: "আমার জন্য Top 10 Bangladeshi cricket players-এর data নিয়ে একটি Excel file বানাও" — Manus নিজেই web search করবে, data collect করবে, Excel বানাবে, ডাউনলোড link দেবে

বাংলাদেশ থেকে অ্যাক্সেস

  • manus.im-এ যান (অথবা manus.ai)
  • Waitlist-এ join করুন (এখনো invite-only, কিন্তু waiting time কমে আসছে)
  • Google/Email দিয়ে signup
  • VPN ছাড়া কাজ করে

কী কাজে ব্যবহার করবেন? ১০টি real use case

  • Market research: "Top 20 SaaS tool for Bangladesh-এর তালিকা + pricing + feature comparison বানাও"
  • Lead generation: "Dhaka-র সব plant-based restaurant-এর নাম + ফোন + ঠিকানা একটি Excel-এ"
  • Travel planning: "Cox's Bazar trip — ৩ দিনের itinerary, hotel option ৩টা, budget breakdown"
  • Content research: "এই topic-এ [...] টপ ৫টি ব্লগ পোস্ট পড়ে একটি summary + আমার আর্টিকেলের outline বানাও"
  • Coding: "এই Python script-টি debug করো, GitHub-এ commit সহ"
  • Data entry automation: "এই PDF থেকে [...] data বের করে Google Sheet-এ পেস্ট করো"
  • Comparison shopping: "এই ফোনের দাম Daraz, Pickaboo, Star Tech-এ check করে compare করো"
  • Job application: "এই job-এর জন্য আমার CV customize করো এবং cover letter লেখো"
  • Investment research: "DSE-তে top 10 dividend-paying stock-এর performance শেষ ৫ বছরের"
  • Daily report: "প্রতিদিন সকাল ৯টায় আমার industry-এর top 5 news collect করো"

কীভাবে একটি ভালো task assign করবেন

  • স্পষ্ট outcome বলুন: "একটি Excel file" / "একটি PDF report" — output format specify করুন
  • Constraints দিন: "শুধু .gov বা .edu source থেকে" / "৫,০০০ শব্দের মধ্যে"
  • Sub-tasks-এ ভেঙে দিন (জটিল কাজে): "প্রথমে [...] করো, তারপর [...]"
  • Verification chain: "প্রতিটি data point-এর source URL সহ দাও"

দাম এবং limit

  • Free trial: Limited credits (কিছু task ফ্রি)
  • Plus ($৩৯/মাস): Higher limits, priority queue
  • Pro ($২০০/মাস): Enterprise features, API access
  • BD পেমেন্ট: International card; দারাজ virtual card কাজ করে কিনা — আপনার test করতে হবে

সীমাবদ্ধতা

  • কখনো কখনো কাজ অসম্পূর্ণ ছেড়ে দেয় (especially long multi-step task)
  • বাংলা বোঝে কিন্তু output বেশিরভাগ ইংরেজিতে
  • খরচ ChatGPT-এর চেয়ে বেশি
  • Sensitive কাজ (banking, password) — এখনো নিরাপদ নয়

অন্যান্য AI agent alternatives

  • Devin (Cognition): Coding-specific autonomous agent
  • OpenAI ChatGPT Agent / Operator: Operator — browser তে কাজ করে
  • Claude Computer Use: Anthropic-এর experimental computer control
  • AutoGPT (open-source): Self-hosted, free, কিন্তু setup জটিল

উপসংহার

Manus এবং তার মতো autonomous agent — আগামী ২ বছরের সবচেয়ে দ্রুত পরিবর্তনশীল AI ক্যাটাগরি। এটি একই কাজে ৫জন intern-এর বদলে ১টি AI agent ব্যবহারের সম্ভাবনা তৈরি করছে।

বাংলাদেশের ফ্রিল্যান্সার বা ছোট agency-গুলোর জন্য এটি একটি অস্ত্র — একই দিনে ৩-৪টা client deliverable শেষ করার ক্ষমতা। Waitlist-এ আজকেই join করুন; access পেলে দেখবেন কাজের ধরন পাল্টে যাচ্ছে।
