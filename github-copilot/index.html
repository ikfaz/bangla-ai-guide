FAQ

GitHub Copilot কী?

এটি GitHub ও OpenAI-এর তৈরি একটি AI কোডিং অ্যাসিস্ট্যান্ট যা VS Code-সহ জনপ্রিয় এডিটরে কোড সাজেস্ট ও অটো-কমপ্লিট করে।

Copilot কী কাজে লাগে?

কোড লেখা দ্রুত করা, ফাংশন ও টেস্ট জেনারেট, কমেন্ট থেকে কোড তৈরি এবং নতুন ভাষা/ফ্রেমওয়ার্ক শেখায় সাহায্য করে।

GitHub Copilot এর দাম কত?

Free (সীমিত), Individual $10/মাস (≈৳১,২২০), Business $19/ইউজার/মাস। শিক্ষার্থীরা Student Pack দিয়ে ফ্রিতে পেতে পারেন।

শিক্ষার্থীরা কি ফ্রিতে পায়?

হ্যাঁ, ভেরিফায়েড শিক্ষার্থী ও শিক্ষকরা GitHub Student Developer Pack-এর মাধ্যমে Copilot ফ্রিতে ব্যবহার করতে পারেন।

বাংলাদেশ থেকে ব্যবহার ও পেমেন্ট?

VPN ছাড়াই ব্যবহার করা যায়; পেইড প্ল্যান কিনতে আন্তর্জাতিক কার্ড লাগে।
